# 우리 영단어 (Uri Vocab)

중1~고3 한국 영어 시험 필수 단어·숙어를 **매일 10~20개씩, 틀린 것 위주로 반복**해서 익히는 모바일 앱입니다.
아이가 여러 명이면 프로필을 나눠 쓰고, 부모님은 같은 앱의 잠긴 영역에서 매일 리포트를 받고 보상 요청을 승인합니다.

Expo(React Native)로 만들어 iOS·Android에서 그대로 돌아가고, **서버 없이 기기 안에서만 동작**합니다.

---

## 무엇을 하는 앱인가

| 요구사항 | 구현 |
|---|---|
| 중1~고3 필수 단어·숙어 | 6개 레벨 × 100개 = **600개** (뜻·동의어·예문 포함) |
| 매일 10~20개 학습 | 하루 목표를 10/12/15/18/20개 중에서 선택 |
| 20개를 10분 동안 깊이 | 한 단어를 3라운드로 만나 20단어 = 60문제 ≈ 10분 |
| 새 단어보다 **틀린 단어 반복** | 간격 반복(SRS)이 복습을 먼저 채우고, 남는 자리에만 새 단어를 넣음 |
| 게임으로 재미있게 | 9가지 문제 유형을 라운드·단어 특성에 맞춰 자동 배정 |
| 같은 단어를 여러 문장으로 | 한 단어에 뜻 1~3개 × 예문 3~4개. 만날 때마다 **다른 뜻·다른 문장** |
| 여러 뜻과 활용을 클릭 없이 | 단어 카드에 **모든 뜻·동의어·예문을 펼쳐서** 표시 |
| 영상으로 노출 | 앱 안 애니메이션 카드 + 실제 발화 영상(YouGlish) 바로가기 |
| 부모님께 매일 통보 | **아이 기기 → 부모님 폰으로 자동 푸시** (서버 없이) + 카톡·문자 공유 |
| 레벨업 시 보상 요청 | 한 학년을 다 외우면 아이가 갖고 싶은 것을 신청 → 부모가 승인/보류 |

## 시작하기

Node.js 18 이상이 필요합니다 (`node --version`으로 확인).

```bash
git clone -b claude/english-vocab-learning-app-pfy9yg https://github.com/yangpa93/yangpa93.git
cd yangpa93/vocab-app
npm install
npm start
```

> `vocab-app` 폴더는 위 기능 브랜치에만 있습니다. 브랜치 지정 없이 clone 하면
> `main`에는 README만 있어서 폴더를 찾을 수 없습니다.

터미널에 뜨는 QR 코드를 휴대폰의 **Expo Go** 앱으로 찍으면 바로 실행됩니다.
(App Store / Play 스토어에서 "Expo Go" 검색)

폰 없이 **컴퓨터 브라우저에서** 바로 보려면 `npm run web`.

안드로이드 **폰과 태블릿 모두 같은 방법**으로 설치합니다. 화면은 세로·가로 모두 돌아가고,
태블릿처럼 넓은 화면에서는 본문이 가운데로 모여 글줄이 지나치게 길어지지 않습니다.

**폰에 진짜 앱으로 설치하려면 → [INSTALL.md](./INSTALL.md)**
안드로이드 APK 만들기, 아이폰 설치, 자주 막히는 곳을 단계별로 정리해 두었습니다.

```bash
npm test            # 로직 테스트 (78개)
npm run typecheck   # 타입 검사
npm run data:validate   # 단어 데이터 무결성 검사
```

## 어떻게 반복 학습이 되나

### 오늘 나올 단어를 고르는 규칙

`src/srs/session.ts`

목표가 15개라면 이 순서로 채웁니다.

1. **복습할 때가 된 단어** — 예정일이 오늘이거나 지난 것. 우선순위가 높은 순.
   기본값은 최대 70%(≈11개)까지.
2. **새 단어** — 남은 자리(≈4개)에만 들어갑니다.
3. 새 단어가 동나면 복습으로 나머지를 채웁니다.

우선순위는 이렇게 매깁니다 (`src/srs/scheduler.ts`의 `priority`).

```
예정일이 지난 일수 × 4
+ 틀린 횟수 × 12
+ 오답률 × 25
+ (한 번도 못 맞힌 단어면) 20
− (이미 외운 단어면) 40
```

**결과적으로 오답이 쌓여 있는 날은 새 단어가 아예 안 나올 수도 있습니다.** 잊지 않게 하는 것이 우선이라는 요구사항을 그대로 옮긴 동작입니다.
새 단어를 더 보고 싶으면 부모님 모드에서 복습 비중을 50%로 낮추면 됩니다.

### 간격이 벌어지는 방식

SM-2를 아이들 시험 대비에 맞게 손봤습니다.

- 맞히면 `1일 → 3일 → 7일 → 14일 → 30일 → 60일`로 완만하게 벌어집니다.
- **틀리면 간격이 0으로 돌아가고, 그날 세션 안에서 한 번 더 나옵니다.**
- 반복해서 틀리는 단어는 난이도 계수(ease)가 깎여서, 같은 단계라도 더 자주 돌아옵니다.
- 간격이 **21일**을 넘기면 "외운 단어"로 봅니다.

### 레벨업

한 학년 단어의 **90%가 21일 간격을 넘기면** 레벨업 화면이 뜹니다.
"올라가기"를 누르면 다음 학년으로 넘어가고, **보상 요청권이 하나 생깁니다.**

## 한 단어를 세 번, 점점 어렵게

4지선다만 반복하면 "아는 것 같은 착각"이 생깁니다. 보기 중에 답이 있어서 알아보기만 하면 되고(재인), 스스로 떠올려 본 적은 없기 때문입니다.
그래서 **한 세션에서 같은 단어를 세 번 만나되, 만날 때마다 어려워지게** 했습니다.

| 라운드 | 단계 | 무엇을 하나 | 문제 유형 |
|---|---|---|---|
| 1 | **익히기** | 뜻을 붙인다 | 뜻 맞히기 · 단어 맞히기 · 듣고 맞히기 |
| 2 | **활용하기** | 문장 안에서 확인한다 | 문맥 속 뜻 · **여러 뜻 구별** · 빈칸 채우기 · 같은 뜻 찾기 |
| 3 | **떠올리기** | 스스로 꺼낸다 | **직접 쓰기(힌트 없음)** · 철자 쓰기 |

**20단어 × 3라운드 = 60문제, 약 10분.**
부모님 모드에서 2회(가볍게) / 3회(표준) / 4회(집중)로 조절할 수 있습니다.

실제 구성 예시 (중1, 새 단어 20개):

```
총 60문항 — 4지선다 33% · 문맥 33% · 직접 쓰기 33%
meaning 10 · word 10 · context 12 · synonym 4 · cloze 2 · polysemy 2 · recall 16 · spelling 4
```

### 설계에 반영한 것

- **한 단어를 연달아 묻지 않습니다.** 라운드마다 순서를 다시 섞어서, 다른 단어를 푸는 사이에 잊었다가 다시 떠올리게 합니다. 바로 다시 물으면 단기 기억에 남아 있어 시험이 되지 않습니다.
- **처음 보는 단어는 문제를 내기 전에 단어 카드를 먼저** 보여 줍니다. 본 적 없는 단어를 4지선다로 물으면 찍기밖에 안 됩니다.
- **모든 4지선다에 "모르겠어요" 보기**가 있습니다. 찍어서 맞히면 앱이 "외웠다"고 잘못 판단해 복습에서 빠져 버립니다. 누르면 오답으로 기록하되 정답을 바로 보여 줍니다.
- **마지막 라운드에서 틀린 단어는 세션 끝에 한 번 더** 나옵니다.

### 문제 유형 9종

| 유형 | 내용 | 난이도 |
|---|---|---|
| 뜻 맞히기 | 영어 → 뜻 4지선다 | ★ |
| 단어 맞히기 | 뜻 → 영어 4지선다 | ★ |
| 듣고 맞히기 | 소리만 듣고 단어 고르기 | ★★ |
| 문맥 속 뜻 | 예문에서 색칠된 단어의 뜻 고르기 | ★★ |
| 빈칸 채우기 | 예문의 표제어를 빈칸으로 | ★★ |
| 같은 뜻 찾기 | 문맥에 맞는 동의어 고르기 | ★★ |
| **여러 뜻 구별** | **보기가 전부 그 단어의 뜻.** 문장을 제대로 읽어야만 고를 수 있음 | ★★★ |
| 철자 쓰기 | 첫 글자 힌트를 보고 타이핑 | ★★★ |
| **직접 쓰기** | **힌트 없이 뜻만 보고 타이핑.** 글자 수만 알려 줌 | ★★★★ |

낼 수 없는 유형은 자동으로 빠집니다 — 뜻이 하나면 '여러 뜻 구별'이 안 나오고, 숙어에는 철자·직접 쓰기를 내지 않습니다.

### 단어 카드 — 모든 뜻을 한 화면에

처음 보는 단어 앞에서, 그리고 문제를 푼 뒤에 **매번** 뜹니다.

**모든 뜻과 모든 예문이 처음부터 펼쳐져 있습니다.** 접어 두고 버튼을 눌러야 보이면 아이는 대부분 누르지 않기 때문입니다.

- 오늘 배우는 뜻이 위쪽에 강조되고, 예문이 한 글자씩 타이핑되며 표제어에 형광펜이 그어집니다.
- 그 아래에 **이 단어의 모든 뜻과 쓰임**이 이어집니다. 뜻마다 동의어와 예문이 전부 보이고, 오늘 배우는 뜻에는 `오늘` 표시가 붙습니다.
- 아무 문장이나 누르면 그 문장을 읽어 줍니다.
- **🎬 실제로 쓰이는 영상 보기** — 그 단어가 발화되는 유튜브 구간(YouGlish)으로 넘어갑니다.

### 어떤 앱을 참고했나

| 앱 | 방식 | 가져온 것 |
|---|---|---|
| [클래스카드](https://namu.wiki/w/%ED%81%B4%EB%9E%98%EC%8A%A4%EC%B9%B4%EB%93%9C) (국내 영어 교사 다수 사용) | 암기 → 리콜 → 스펠 → 테스트 4단계 | **같은 단어를 단계별로 반복**, 4지선다의 '모름' 보기 |
| [Quizlet Learn](https://quizlet.com/help/2762234/studying-with-learn) | 맞힐수록 객관식 → 서술형으로 자동 승급 | **정답이 쌓이면 어려운 유형으로 올리기** |
| [Vocabulary.com](https://www.vocabulary.com/how-it-works/) | 10가지 문제 유형, 20단계 숙련도 | **Sentence Definition → 문맥 속 뜻**, **Polysemous Sentence Synonym → 여러 뜻 구별** |
| 워드마스터 학습앱 | 뜻 맞추기 + 영단어 맞추기 + 스펠링 | 한 단어를 방향을 바꿔 가며 묻기 |

교육심리 쪽 근거로는, 자유회상·단답형이 4지선다보다 학습 효과가 크지만
**좋은 오답 보기와 즉각적인 정답 공개가 있으면 4지선다도 충분히 효과가 있다**는 연구를 참고했습니다
([retrieval practice 리뷰](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2019.00005/full)).
그래서 4지선다를 없애지 않고 **반드시 직접 쓰기까지 올라가는 구조**로 만들고, 틀린 보기를 눌러도 정답을 바로 보여 줍니다.

### 같은 단어, 매번 다른 문장

`src/data/entry.ts`의 `exposure()`가 노출 횟수를 인덱스로 돌려 씁니다.
뜻을 바깥 루프, 예문을 안쪽 루프로 돌려서 **뜻이 2개면 번갈아 나옵니다.**

```
save (뜻 3개 × 예문 2~3개)
 0회차 → 구하다      "The doctor saved his life."
 1회차 → 아끼다      "We should save water."
 2회차 → 저축하다    "I am saving money for a bike."
 3회차 → 구하다      "He saved a puppy from the river."   ← 뜻은 같지만 문장이 다름
```

## 부모님 모드

홈 화면 오른쪽 위 `👨‍👩‍👧 부모님` → PIN 입력.

- **학습 리포트** — 오늘 학습량/정답률/학습 시간/연속 일수, 최근 7일 막대그래프, 레벨 진도,
  **오늘 틀린 단어**와 **누적으로 자주 틀리는 단어**. 아이가 여럿이면 위쪽 탭으로 전환합니다.
- **리포트 공유하기** — 리포트를 텍스트로 만들어 카카오톡·문자로 보냅니다.
- **보상 요청** — 아이가 올린 요청을 승인/보류하고 한마디를 남깁니다. 승인된 뒤 "약속 지켰어요"로 마무리 표시.
- **설정** — 알림 시각(오후 6~10시), 하루 목표, **학습 강도(2~4회)**, 복습 비중, 소리/진동, 학년 수동 조정, PIN 변경.

### 매일 알림

정해진 시각에 기기 로컬 알림이 뜹니다.

```
📚 오늘의 영단어 학습 리포트
서준 · 오늘 목표 완료! 15개 · 정답률 87% · 5일 연속
지호 · 오늘 아직 학습을 시작하지 않았어요.
```

`목표를 못 채웠을 때만` 옵션을 켜면 미달인 아이만 알립니다.

> **로컬 알림의 한계**: 알림 본문은 예약하는 순간의 상태로 굳습니다. 그래서 앱이 홈 화면에 올 때마다 다시 예약합니다.

## 부모님 폰으로 자동 전송 (서버 없이)

아이 기기와 부모님 폰이 따로일 때, **아이가 학습을 마치면 부모님 폰으로 알림이 바로 갑니다.**
서버를 두지 않고 Expo 푸시 서비스를 중계로 씁니다.

```
아이 기기 ──(HTTPS POST)──▶ Expo 푸시 서버 ──▶ 부모님 폰
```

### 한 번만 하는 연결

1. **부모님 폰**에 같은 앱을 설치 → 부모님 모드 → `부모님 폰 연결` → **이 폰을 부모님 전용으로 쓰기**
2. 폰 이름을 정하고 **연결 링크 보내기** → 카카오톡으로 아이 기기에 전송
3. **아이 기기**에서 그 링크를 한 번 누르면 끝. 링크가 안 열리면 주소를 복사해 붙여넣어도 됩니다.

아이가 여럿이면 기기마다 한 번씩 연결합니다. 같은 링크를 그대로 쓰면 됩니다.
카메라 권한이 필요 없도록 QR 스캔 대신 링크·붙여넣기 방식을 썼습니다.

### 부모님 폰에서 보이는 것

- 학습이 끝나는 **즉시** 알림이 뜹니다 — `📚 서준 학습 리포트 · 오늘 목표 완료! 20개 · 정답률 87%`
- 알림을 지워도 앱 안에 날짜별로 쌓입니다. 틀린 단어까지 그대로 남습니다.
- **밤까지 리포트가 오지 않으면** 부모님 폰이 스스로 `📭 오늘 학습 리포트가 오지 않았어요`를 띄웁니다.
  아이 기기가 꺼져 있으면 아무것도 안 오는데, 그러면 "안 한 건지 앱이 고장 난 건지" 알 수 없기 때문입니다.

### 제약

- **Expo Go에서는 동작하지 않습니다.** EAS로 빌드한 APK여야 푸시 토큰이 나옵니다. `eas init`도 미리 해 두어야 합니다.
- **아이가 앱을 열어 학습을 마쳐야** 전송됩니다. 기기가 꺼져 있으면 못 보냅니다(위의 '안 왔어요' 알림이 이를 메웁니다).
- **리포트 내용이 Expo 서버를 한 번 지나갑니다.** 아래 보안 절에 자세히 적었습니다.
- 부모님이 앱을 지우면 토큰이 죽습니다. 다시 설치하고 연결을 새로 해야 합니다.

### PIN에 대해

PIN은 기기에 평문으로 저장됩니다. **보안 장치가 아니라 아이가 리포트를 지우거나 스스로 보상을 승인하는 것을 막는 실수 방지 장치**입니다.
금융 수준의 보호가 필요하다면 `expo-secure-store`와 서버 인증으로 바꿔야 합니다.

## 단어를 어떻게 골랐나

3단계로 선정했습니다.

1. **기본 뼈대 — 교육부 「기본 어휘 목록」**
   개정 영어과 교육과정 별표에 실린 약 3,000개 어휘가 공식 기준입니다. 교과서는 원칙적으로 이 목록 안에서 나옵니다.
2. **레벨 배정 — 교과서 공통 출현**
   5대 검정 교과서(동아·천재·YBM·미래엔·비상)에 공통으로 나오는 어휘를 학년별로 배치했습니다.
   중1은 기초 동사·형용사, 중3부터 추상 명사, 고2~3은 수능 지문형 어휘로 올라갑니다.
3. **고등 구간 — 수능·모평 기출 빈도 + EBS 연계**
   고1~고3은 평가원 기출 지문 빈도가 높은 어휘와 빈출 구동사·관용구 위주입니다.

각 항목에 `source` 태그(`curriculum` / `textbook` / `csat`)를 달아 두어 나중에 출처별로 걸러낼 수 있습니다.

### 지금 들어 있는 양

| 레벨 | 단어 수 | 성격 |
|---|---|---|
| 중1 | 100 | 기초 동사·형용사, 기본 구동사 |
| 중2 | 100 | 추상 명사, 파생어 등장 |
| 중3 | 100 | 독해용 어휘, 연결어 |
| 고1 | 100 | 학평 지문 빈출 |
| 고2 | 100 | 논설·과학 지문 어휘 |
| 고3 | 100 | 수능 빈칸 추론 핵심 어휘 |

**총 600개 단어 / 약 2,000개 예문.**

### 레벨당 300개 이상으로 늘리기

스프레드시트로 정리해서 CSV 한 장으로 부어 넣으면 됩니다.

```bash
node scripts/import-csv.mjs 중1단어.csv m1 > src/data/levels/m1.ts
npm run data:validate
```

CSV 열 순서 (첫 줄은 헤더):

```
word, pos, meaning, synonyms, ex1_en, ex1_ko, ex2_en, ex2_ko, ex3_en, ex3_ko, ex4_en, ex4_ko
```

- `synonyms`는 `;`로 구분합니다. 예: `rescue;save from`
- **같은 단어를 여러 줄에 적으면 뜻이 여러 개인 것으로 합쳐집니다.** 다의어는 뜻마다 한 줄씩.
- 예문이 3개 미만이면 경고가 뜹니다(파일은 그대로 생성됩니다).

`data/sample-words.csv`에 예시가 들어 있습니다.

`npm run data:validate`가 검사하는 것: id 중복, 같은 레벨 내 표제어 중복, 빈 필드,
단어당 예문 3개 이상, 숙어 분류, **예문에 표제어가 실제로 들어 있는지**, 동의어에 자기 자신이 없는지.

### 데이터가 저장되는 곳

기기 안 AsyncStorage에만 저장됩니다. 밖으로 나가지 않습니다.

- `urivocab:root:v1` — 프로필 목록, 부모 설정, 보상 요청
- `urivocab:data:v1:<프로필 id>` — 그 아이의 카드·일별 기록·답안 로그

아이별로 키를 나눠서, 한 아이가 학습하는 동안 다른 아이 데이터를 건드리지 않습니다.

> 앱을 지우면 기록도 사라집니다. 백업이 필요하면 서버나 파일 내보내기를 붙여야 합니다.

## 보안과 개인정보

서버가 없다는 것이 실제로 없애 주는 위험과, 그래도 남는 위험을 나눠서 적습니다.

### 서버가 없어서 사라진 위험

**우리 계정 시스템도, 우리 서버도, 우리 DB도 없습니다.** 그래서 DB 유출, 계정 탈취, 비밀번호 재사용 피해가 원천적으로 없습니다.
아이들 데이터가 한곳에 모여 있지 않아서, 누가 털어 갈 "덩어리"가 존재하지 않습니다.

### 밖으로 나가는 통신은 딱 하나

앞서 "네트워크 호출이 한 줄도 없다"고 적었으나, **부모님 폰 자동 전송을 넣으면서 더 이상 사실이 아닙니다.**

| 언제 | 어디로 | 무엇이 |
|---|---|---|
| 아이가 학습을 마쳤을 때 | Expo 푸시 서버 (`exp.host`) | 아이 이름, 날짜, 학습량, 정답률, 틀린 단어 |

이게 전부입니다. 다른 어떤 통신도 하지 않습니다.
🎬 버튼은 앱이 통신하는 게 아니라 **기기의 브라우저를 여는 것**이라 여기에 해당하지 않습니다.

**연결하지 않으면 이 통신도 없습니다.** 부모님 폰을 연결하지 않거나, 부모님 모드에서 `학습 후 자동 전송`을 끄면
앱은 예전처럼 완전히 오프라인으로 동작합니다.

Expo 푸시 서버는 알림을 배달만 하고 보관하지 않지만, 전달 과정에서 내용이 **제3자 서버를 지나간다**는 점은 사실입니다.
아이 이름 대신 별명을 쓰시면 이 부분이 거의 무의미해집니다.

> **푸시 토큰에 대해**: 부모님 폰의 푸시 토큰을 아는 사람은 그 폰으로 알림을 보낼 수 있습니다.
> 카카오톡으로 링크를 보낼 때 엉뚱한 방에 보내지 않도록만 주의하시면 됩니다.
> 토큰으로 학습 기록을 읽어 갈 수는 없습니다 — 보내기만 가능하고 가져오기는 불가능합니다.

### 그래도 남는 위험

| 위험 | 실제 영향 | 대응 |
|---|---|---|
| **PIN이 평문 저장** | 폰이 루팅/탈옥됐거나 백업 파일에 접근하면 읽을 수 있음 | 아이의 무단 접근을 막는 용도라 현 수준으로 충분. 더 필요하면 `expo-secure-store`로 교체 |
| **기기 분실·도난** | 학습 기록이 그 폰에만 있음. 원격 삭제 불가 | 폰 잠금화면 암호를 걸어 두는 것이 사실상의 방어선 |
| **npm 의존성 (777개)** | 패키지 하나가 오염되면 위험. **서버 없는 앱에서 가장 현실적인 위험** | `npm audit` 정기 확인, Expo SDK 업데이트 |
| **APK 사이드로딩** | "출처를 알 수 없는 앱" 허용 습관 자체가 위험 | 설치 후 그 설정을 다시 끄기 |
| **YouGlish 외부 링크** | 유튜브로 이어져 아이가 다른 영상을 볼 수 있음 | 해킹이 아니라 **콘텐츠 노출** 문제. 원하면 이 버튼을 뺄 수 있음 |

### 저장되는 개인정보

기기 안에만 저장되고 밖으로 나가지 않습니다.

- 저장하는 것: 아이 이름(별명 가능), 이모지, 학년, 학습 기록, 오답 단어, 보상 요청 문구, 부모 PIN
- **저장하지 않는 것: 전화번호, 이메일, 주소, 사진, 위치, 결제 정보**

유출되더라도 피해가 크지 않은 수준입니다. 걱정되시면 **이름 대신 별명**을 쓰시면 됩니다.

### 현재 알려진 취약점

`npm audit` 기준 moderate 11건이며, 근본 원인은 **한 가지**입니다.

```
uuid 7.0.3 — buffer 경계 검사 누락 (GHSA-w5hq-g745-h8pq)
경로: expo-splash-screen → @expo/config-plugins → xcode → uuid
```

`xcode`는 Xcode 프로젝트 파일을 다루는 **빌드 도구**라서 앱에 포함되지 않고 실행되지도 않습니다.
Expo가 상위 패키지를 갱신하면 자연히 해소됩니다.

## 알아 두면 좋은 제약

- **부모 알림은 이 기기에서만** 뜹니다. 부모님 폰으로 실시간 전송하려면 백엔드가 필요합니다.
  당장은 리포트 공유하기(카카오톡·문자)로 대신할 수 있습니다.
- **영상은 YouGlish 링크**입니다. 앱이 영상을 직접 보유하지 않고 외부 브라우저로 넘깁니다.
  자체 영상을 만들어 올리는 것은 제작비와 저작권 문제가 커서 제외했습니다.
- **발음은 기기 TTS**를 씁니다. 기기에 영어 음성이 없으면 조용히 넘어가고, 학습은 계속됩니다.
- **빈칸 채우기는 규칙 기반 굴절형 매칭**이라 불규칙 동사(go/went)는 놓칩니다.
  그때는 다른 게임이 배정되므로 학습에 지장은 없습니다.
- 데이터는 손으로 검수했지만 600개 전부가 완벽하다고 보장할 수는 없습니다.
  이상한 뜻이나 예문을 발견하면 해당 `src/data/levels/*.ts`에서 바로 고치면 됩니다.
