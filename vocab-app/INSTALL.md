# 설치 안내

폰에 앱을 올리는 방법은 세 가지입니다. **1번 → 2번 순서로 하시는 걸 권합니다.**

| 방법 | 걸리는 시간 | 비용 | 알림 기능 | 추천 대상 |
|---|---|---|---|---|
| ① Expo Go | 5분 | 무료 | 제한적 | 지금 당장 화면·게임을 보고 싶을 때 |
| ② APK 설치 (안드로이드) | 20분 | 무료 | ✅ 완전 동작 | 안드로이드폰에서 제대로 쓸 때 |
| ③ 아이폰 설치 | 30분 | 연 $99 | ✅ 완전 동작 | 아이폰에서 제대로 쓸 때 |

---

## ① Expo Go — 5분 만에 화면 보기

설치 파일을 만들 필요 없이 개발용 서버에 붙어서 바로 실행합니다.
**단어 학습, 게임, 부모 리포트 화면까지 전부 확인할 수 있습니다.**

### 준비

컴퓨터와 폰이 **같은 와이파이**에 있어야 합니다.

1. 폰에 **Expo Go** 앱을 설치합니다.
   - 아이폰: App Store에서 "Expo Go" 검색
   - 안드로이드: Play 스토어에서 "Expo Go" 검색

2. 컴퓨터에서 프로젝트를 받아 실행합니다.

```bash
git clone https://github.com/yangpa93/yangpa93.git
cd yangpa93/vocab-app
npm install
npm start
```

3. 터미널에 QR 코드가 뜹니다.
   - **아이폰**: 기본 카메라 앱으로 QR을 비추면 배너가 뜹니다. 누르면 Expo Go가 열립니다.
   - **안드로이드**: Expo Go 앱을 열고 안에 있는 `Scan QR code`로 찍습니다.

### 같은 와이파이가 안 될 때

회사·학교 와이파이는 기기끼리 통신을 막아 두는 경우가 있습니다. 그럴 땐 터널 모드로 바꾸세요.

```bash
npx expo start --tunnel
```

느리지만 어떤 네트워크에서든 연결됩니다.

### 이 방법의 한계

- **컴퓨터를 켜 두어야** 폰에서 앱이 돌아갑니다. 터미널을 닫으면 앱도 멈춥니다.
- **매일 리포트 알림이 제대로 오는지는 확인할 수 없습니다.** Expo Go는 자체 앱 이름·아이콘으로 알림이 뜨고, 안드로이드에서는 알림 지원에 제약이 있습니다.
- 앱 아이콘이 Expo Go 아이콘으로 보입니다.

알림까지 확인하시려면 ②번으로 가세요.

## ② 안드로이드 APK — 진짜 앱으로 설치

설치 파일(`.apk`)을 만들어 폰에 직접 넣습니다. **컴퓨터를 꺼도 앱이 돌아가고, 매일 알림도 정상 동작합니다.**
안드로이드는 애플처럼 개발자 등록비가 필요 없습니다.

### 1단계 — Expo 계정 만들기 (무료)

https://expo.dev/signup 에서 가입합니다. 이메일만 있으면 됩니다.

### 2단계 — 빌드 도구 설치와 로그인

```bash
npm install -g eas-cli
eas login
```

방금 만든 계정으로 로그인합니다.

### 3단계 — 프로젝트 연결

```bash
cd yangpa93/vocab-app
eas init
```

`Would you like to create a project?` 라고 물으면 **y**를 누릅니다.
`app.json`에 프로젝트 ID가 자동으로 채워집니다.

### 4단계 — 빌드

```bash
eas build --platform android --profile preview
```

- 처음 한 번은 `Generate a new Android Keystore?` 라고 묻습니다. **y**를 누르면 알아서 만들어 줍니다.
- 빌드는 Expo 서버에서 돌아갑니다. **10~20분** 걸립니다. 터미널을 닫아도 계속 진행됩니다.
- 끝나면 다운로드 링크가 뜹니다. https://expo.dev 의 내 프로젝트 → Builds 에서도 볼 수 있습니다.

> 무료 계정은 월 빌드 횟수에 제한이 있습니다. 가족끼리 쓰기에는 충분합니다.

### 5단계 — 폰에 설치

1. 빌드가 끝나면 터미널에 **QR 코드**가 뜹니다. 폰 카메라로 찍으면 다운로드 페이지가 열립니다.
   (또는 링크를 카톡으로 자신에게 보내서 폰에서 여세요.)
2. `.apk` 파일을 내려받습니다.
3. 다운로드한 파일을 누르면 **"출처를 알 수 없는 앱"** 경고가 뜹니다.
   `설정` → `이 출처 허용`을 켜고 설치합니다.
   (스토어를 거치지 않은 앱이라 나오는 정상적인 경고입니다.)
4. 홈 화면에 **우리 영단어** 아이콘이 생깁니다.

### 6단계 — 알림 켜기

앱을 처음 열고 부모님 모드에 들어가면 알림 권한을 묻습니다. **허용**을 누르세요.
안드로이드 13 이상에서는 이 권한이 없으면 리포트 알림이 오지 않습니다.

### 아이를 여러 명 쓰거나 폰을 바꿀 때

학습 기록은 **그 폰 안에만** 저장됩니다. 앱을 지우거나 폰을 바꾸면 기록이 사라집니다.
백업이 필요하시면 말씀해 주세요. 파일로 내보내고 불러오는 기능을 넣을 수 있습니다.

## ③ 아이폰 설치

애플은 스토어를 거치지 않은 앱 설치를 훨씬 엄격하게 막습니다. **애플 개발자 계정(연 $99)이 필요합니다.**

### 개발자 계정이 있다면

```bash
eas build --platform ios --profile preview
```

- 애플 계정으로 로그인하라는 안내가 나옵니다.
- 설치할 아이폰을 미리 등록해야 합니다. `eas device:create`를 실행하면 QR이 나오고, 그 폰으로 찍어 등록합니다.
- 빌드가 끝나면 안드로이드와 같은 방식으로 QR을 찍어 설치합니다.

### 개발자 계정이 없다면

현실적인 선택지는 둘입니다.

- **Expo Go로 쓴다** (①번). 매일 알림만 포기하면 학습 기능은 전부 됩니다.
- **아이는 안드로이드폰으로 학습하고, 부모님은 리포트 공유하기(카톡·문자)로 받는다.**

맥이 있으시면 무료 애플 계정으로 7일짜리 임시 설치가 가능하지만, 일주일마다 다시 설치해야 해서 실용적이지 않습니다.

## 자주 막히는 곳

**`npm install`에서 오류가 납니다**
Node.js 버전을 확인하세요. 18 이상이 필요합니다. `node --version`으로 확인하고, 낮으면 https://nodejs.org 에서 LTS 버전을 받으세요.

**QR을 찍었는데 연결이 안 됩니다**
컴퓨터와 폰이 같은 와이파이인지 확인하세요. 그래도 안 되면 `npx expo start --tunnel`로 실행하세요.

**`eas build`가 `project ID`가 없다고 합니다**
`eas init`을 먼저 실행하세요.

**앱이 켜지자마자 꺼집니다**
`npm start` 터미널에 빨간 오류 메시지가 남아 있을 겁니다. 그 내용을 알려 주세요.

**소리가 안 나옵니다**
기기에 영어 음성이 설치되어 있어야 합니다.
안드로이드는 `설정 → 접근성 → 텍스트 음성 변환`에서 영어를 추가하고, 아이폰은 `설정 → 손쉬운 사용 → 음성 콘텐츠`에서 확인하세요.
음성이 없어도 학습은 그대로 진행됩니다.

**알림이 안 옵니다**
① Expo Go로 실행 중이면 정상입니다 — ②번 APK로 설치해야 합니다.
② 앱 설정에서 알림 권한이 허용되어 있는지 확인하세요.
③ 부모님 모드 → 설정에서 `알림 받기`가 켜져 있는지, 알림 시각이 이미 지나지 않았는지 확인하세요.
