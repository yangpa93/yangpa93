# 안드로이드 베타 — 처음부터 끝까지

## 1. 준비 (컴퓨터에서 한 번만)

[INSTALL.md의 0단계](./INSTALL.md#0단계--컴퓨터-준비-두-경로-공통)를 아직 안 하셨으면 먼저 하세요
(`node` 설치 → 코드 받기 → `npm install`).

그다음 아래를 순서대로 하시면 됩니다.

```powershell
cd yangpa93\vocab-app
git pull origin claude/english-vocab-learning-app-pfy9yg
npm install

npx eas-cli@latest login    # Expo 계정 (없으면 https://expo.dev/signup)
npx eas-cli@latest init     # 프로젝트 ID를 app.json에 박습니다
```

> **`npm install`을 꼭 다시 하세요.** 네이티브 모듈이 세 개 늘었습니다
> (`expo-file-system`, `expo-sharing`, `expo-application`). 예전에 만든 APK에는
> 이 모듈이 없어서 **백업 화면을 열면 앱이 꺼집니다.** 반드시 다시 빌드해야 합니다.

> **`eas`는 프로젝트가 아니라 컴퓨터에 따로 있는 도구입니다.** `npm install`을
> 했다고 생기지 않습니다. 위처럼 `npx eas-cli@latest` 로 부르면 설치 없이 바로
> 쓸 수 있습니다. 처음 한 번 `Ok to proceed?`를 물으면 Enter를 누르세요.
>
> 매번 `npx`를 붙이기 싫으면 `npm install -g eas-cli` 로 깔고 **PowerShell 창을
> 완전히 닫았다 새로 여세요.** 열려 있던 창은 예전 PATH를 들고 있어서 방금 깐
> `eas`를 계속 못 찾습니다. 새 창에서 `eas --version` 이 뜨면 그때부터는
> `eas build ...` 처럼 짧게 쓰셔도 됩니다.
>
> `eas init`은 **꼭 해야 합니다.** 안 하면 앱은 멀쩡히 설치되고 학습도 되는데
> **부모님 폰 전송만 조용히 안 됩니다.** 아래 점검이 이것을 잡아 줍니다.

## 2. 빌드 전 점검 — 몇 초면 끝납니다

EAS 빌드는 한 번에 10~20분이 걸리고 무료 계정은 월 횟수가 정해져 있습니다.
**설정 한 줄이 빠져서 빌드를 날리는 일**을 막으려고 점검 스크립트를 넣었습니다.

```bash
npm run preflight android
npm test
npm run typecheck
```

`preflight`가 이런 것을 봅니다.

```
빌드 전 점검 — android

  ✅ 판 0.9.0 (베타)
  ✅ 알림 아이콘 있음
  ✅ POST_NOTIFICATIONS 권한 있음 (안드로이드 13+ 알림)
  ✅ 불필요한 권한 3개 차단됨
  ✅ 패키지 com.yangpa93.urivocab
  ✅ 어휘 3286개 전부 수록

  ❌ app.json에 EAS 프로젝트 ID가 없습니다. `eas init`을 먼저 하세요.
```

**❌가 하나라도 있으면 빌드하지 마세요.** 특히 `eas init`을 안 하고 빌드하면
앱은 멀쩡히 설치되고 학습도 되는데 **부모님 폰 전송만 조용히 안 됩니다.**
깔아 보기 전에는 눈치채기 어려운 종류의 고장입니다.

## 3. 빌드

```powershell
npx eas-cli@latest build --platform android --profile beta-android
```

처음 한 번만 묻습니다.

- `Generate a new Android Keystore?` → **y**
  (앱 서명 열쇠입니다. Expo가 만들어 보관하니 직접 관리할 필요 없습니다.)

**10~20분** 걸립니다. 터미널을 닫아도 클라우드에서 계속 진행되고,
`https://expo.dev/accounts/.../builds/...` 링크에서 실시간으로 보입니다.

> **이 키스토어를 잃어버리면 기존 앱 위에 덮어쓰기가 안 됩니다.** 같은 Expo
> 계정으로만 계속 빌드하시면 Expo가 알아서 같은 열쇠를 씁니다.

## 4. 작은딸 폰에 설치

1. 빌드가 끝나면 터미널에 **QR 코드**가 뜹니다.
   폰 **기본 카메라 앱**으로 찍으면 다운로드 페이지가 열립니다.
   (또는 `expo.dev` 링크를 카톡으로 보내 폰에서 열고 `Install`)
2. `Install` → `.apk` 내려받기
3. **"이 출처의 앱은 설치할 수 없습니다"** 경고 →
   `설정` → **"이 출처 허용"** 켜기 → 뒤로 → `설치`
   (스토어를 안 거친 앱이라 나오는 정상 경고입니다)
4. 첫 실행에서 **알림 권한을 묻습니다 → 반드시 허용**
5. **설치가 끝나면 "이 출처 허용"을 다시 꺼 두세요.**

## 5. 잘 깔렸는지 3분 확인

아이에게 넘기기 전에 부모님이 먼저 보세요.

- [ ] 홈 화면 위에 **`🧪 베타 0.9.0 (1) · android`** 칩이 보이는가
- [ ] 프로필을 만들고 `공부 시작하기` → 문장 빈칸 문제가 나오는가
- [ ] 🔊 를 누르면 영어 발음이 들리는가
- [ ] 부모님 모드 → 설정 → `학습 기록 백업` → **`백업 파일 내보내기`가 되는가**
      ← 새로 넣은 기능이라 여기서 앱이 꺼지면 `npm install`을 빠뜨린 것입니다
- [ ] 부모님 모드 → 설정에서 **알림 시각을 5분 뒤로** 맞추고 홈에 다녀온 뒤
      앱을 닫아 두면 알림이 뜨는가 ← **안 뜨면 알림 권한을 다시 보세요**

## 6. 새 빌드를 올린 뒤

같은 명령을 다시 돌리고, 나온 APK를 **기존 앱 위에 그대로 설치**합니다.
지울 필요 없고 **학습 기록도 그대로 남습니다.**

빌드 번호는 `autoIncrement`로 자동으로 올라갑니다. 아이 폰의 칩이
`(1)` → `(2)`로 바뀌면 새 빌드가 들어간 것입니다.

## 7. APK를 다시 안 만들고 고치기 (무선 업데이트)

`beta-android` 프로필에 `channel: "beta"`가 있어서 **EAS Update**를 쓸 수 있습니다.
화면 글귀, 예문, 문제 배정 같은 **자바스크립트만 바뀐 것**은 APK를 다시 만들지 않고
바로 밀어 넣을 수 있습니다. 아이가 앱을 다시 켜면 적용됩니다.

```powershell
npx eas-cli@latest update --branch beta --message "예문 오타 수정"
```

**1~2분**이면 끝납니다. 20분짜리 빌드를 안 돌려도 되니, 예문 10,047개를 다듬는
동안 특히 편합니다.

무선 업데이트로 안 되는 것도 있습니다. **네이티브 모듈이 늘거나, app.json의
권한·아이콘·판 번호가 바뀌면 반드시 APK를 다시 만들어야** 합니다.
(백업 기능을 넣을 때 `expo-file-system`이 늘었던 것이 그런 경우입니다.)

> **무선 업데이트를 받으면 칩에 한 칸이 더 붙습니다.**
> `🧪 베타 0.9.0 (1) · android · 업데이트 a3f9c2`
> 빌드 번호는 그대로인데 안의 내용이 바뀌었다는 표시입니다. 이게 없으면
> 같은 `(1)`이 서로 다른 두 앱을 가리키게 됩니다.

## 나중에 — 아이폰 베타

안드로이드로 충분히 굴려 보고 넘어오세요. 준비는 [INSTALL.md 경로 1](./INSTALL.md#경로-1--큰딸-아이폰-testflight)에 있습니다.

```powershell
npm run preflight ios
npx eas-cli@latest build --platform ios --profile beta-ios
npx eas-cli@latest submit --platform ios --latest
```

| 프로필 | 나오는 것 | 쓰는 곳 |
|---|---|---|
| `beta-android` | `.apk` (내부 배포) | 작은딸 폰에 직접 설치 |
| `beta-ios` | `.ipa` (App Store 서명) | `eas submit` → TestFlight |

두 프로필 모두 `autoIncrement`가 켜져 있어서 **빌드할 때마다 빌드 번호가 자동으로 올라갑니다.**
같은 번호로 두 번 올리면 애플이 거절하기 때문입니다.

## 베타에서 꼭 봐 달라고 할 것

### 아이에게

- [ ] 문제를 풀 때 **같은 문장이 계속 나오지는 않는가** ← 이번에 고친 부분
- [ ] `반대말 찾기` 문제의 보기가 **아는 단어들로 나오는가** ← 이번에 새로 넣음
- [ ] 뜻이 여러 개인 단어(`plot`, `palm`, `yield` 등)에서 뜻마다 다른 문장이 나오는가
- [ ] 🔊 를 누르면 영어 발음이 들리는가
- [ ] 틀린 뒤 다시 나올 때 **다른 문장으로** 나오는가
- [ ] 하루치를 끝내는 데 몇 분 걸렸는지 (목표는 10~15분)
- [ ] 지루하거나 너무 어려운 유형이 있는지

### 부모님이

- [ ] **백업 내보내기 → 카톡으로 자기에게 보내기 → 가져오기**가 되는가 ← 이번에 새로 넣음
- [ ] 요구권 금액을 바꾸면 아이 화면의 금액도 바뀌는가
- [ ] 아이가 `⭐️ 이번엔 정말 잘했어요`로 1만원 더 요구하면 부모 화면에 이유까지 오는가
- [ ] `기본 금액만 주기`가 제대로 동작하는가
- [ ] 아이 기기에서 학습을 끝내면 **부모 폰에 알림이 오는가**
- [ ] 학습 달력에 어제·오늘이 제대로 찍히는가

### 백업은 특히 꼼꼼히

가장 중요하고 가장 새로운 기능입니다. **아이 기기에서 한 번은 꼭 해 보세요.**

1. 부모님 모드 → 설정 → `학습 기록 백업` → `내보내기 · 가져오기`
2. `백업 파일 내보내기` → 카카오톡으로 **나에게 보내기**
3. 그 파일을 눌러 저장한 뒤, 같은 화면에서 `백업 파일 고르기`
4. **무엇이 들어 있는지 먼저 보여주는 화면**이 뜨는지 확인
   (아이 이름 · 레벨 · 공부한 날 수 · 익힌 단어 수)
5. `아이만 가져오기`를 눌러 아이가 하나 더 생기는지 확인
   → 확인했으면 그 복제본은 설정에서 지우면 됩니다

> **`통째로 되돌리기`는 지금 기록을 지웁니다.** 시험해 보실 거면 **먼저 내보내기부터**
> 하세요. 그래야 되돌릴 것이 남습니다.

## 베타 동안 알아 두실 것

- **백업 파일에 부모 PIN은 안 들어갑니다.** 파일이 카톡·드라이브를 돌아다니는데
  PIN이 적혀 있으면 아이가 열어 보고 그대로 쓸 수 있어서입니다.
  되돌린 뒤에는 PIN을 다시 정하세요.
- **부모님 폰 연결도 백업에 안 들어갑니다.** 새 기기에서 다시 연결하는 편이 맞습니다.
- **TestFlight 빌드는 90일 뒤 만료**됩니다. 만료되면 앱이 안 열리니
  [INSTALL.md의 1-7](./INSTALL.md#1-7-90일마다-다시-올리기--꼭-기억하세요)을 보고 다시 올리세요.
  학습 기록은 남아 있습니다.
- **아직 결제가 없습니다.** 판매하시려면 무료 체험 경계와 인앱 결제를 먼저 붙여야 합니다.

## 되돌아가야 할 때

베타가 크게 잘못됐으면 이전 빌드로 되돌릴 수 있습니다.

- **TestFlight** — 이전 빌드가 만료 전이면 TestFlight 앱에서 그것을 다시 설치할 수 있습니다.
- **APK** — 예전 APK 파일을 갖고 계시면 그대로 다시 설치하면 됩니다.
  (빌드 링크는 https://expo.dev 의 프로젝트 → Builds에 남아 있습니다.)

어느 쪽이든 **되돌리기 전에 백업부터 내보내 두세요.**
