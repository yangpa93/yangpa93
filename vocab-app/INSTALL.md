# 안드로이드 설치 안내

안드로이드폰에 올리는 방법은 세 가지입니다.

| 방법 | 시간 | 준비물 | 알림 | 컴퓨터를 꺼도? |
|---|---|---|---|---|
| **A. Expo Go** | 5분 | 없음 | ❌ | ❌ 켜 둬야 함 |
| **B. EAS 클라우드 빌드 → APK** | 20분 | Expo 계정(무료) | ✅ | ✅ |
| **C. USB 직접 설치** | 30분~1시간 | Android Studio | ✅ | ✅ |

**A로 먼저 화면을 확인하고, B로 넘어가시는 걸 권합니다.**
C는 Android Studio(용량 큼)를 이미 쓰고 계실 때만 의미가 있습니다.

---

## 0단계 — 컴퓨터 준비 (모든 방법 공통)

### Node.js 확인

터미널(윈도우는 `PowerShell`, 맥은 `터미널`)을 열고:

```bash
node --version
```

`v18.0.0` 이상이 나와야 합니다.
아무것도 안 나오거나 버전이 낮으면 https://nodejs.org 에서 **LTS** 버전을 받아 설치하고 터미널을 다시 여세요.

### 코드 받기

```bash
git clone https://github.com/yangpa93/yangpa93.git
cd yangpa93/vocab-app
git checkout claude/english-vocab-learning-app-pfy9yg
npm install
```

`npm install`은 처음 한 번 2~5분 걸립니다.
중간에 `deprecated`, `warn` 같은 노란 글씨가 여러 줄 나오는데 **정상입니다.** 빨간 `ERR!`만 아니면 넘어가세요.

> `git`이 없다는 오류가 나면 https://git-scm.com 에서 설치하시거나,
> GitHub 페이지에서 `Code → Download ZIP`으로 받아 압축을 푸셔도 됩니다.

## A. Expo Go — 5분 만에 화면 확인

설치 파일 없이 컴퓨터의 개발 서버에 붙어서 실행합니다.
**단어 학습, 게임 6종, 단어 스토리 카드, 부모 리포트까지 전부 확인 가능합니다.**

### A-1. 폰에 Expo Go 설치

Play 스토어에서 **Expo Go** 검색 → 설치.

### A-2. 서버 실행

컴퓨터에서:

```bash
npm start
```

터미널에 QR 코드와 함께 `Metro waiting on exp://192.168.x.x:8081` 같은 주소가 뜹니다.

### A-3. 폰에서 열기

**컴퓨터와 폰이 같은 와이파이여야 합니다.**

폰에서 **Expo Go 앱을 열고** → 안에 있는 `Scan QR code` 를 눌러 컴퓨터 화면의 QR을 찍습니다.
(안드로이드는 기본 카메라 앱이 아니라 **Expo Go 안에서** 찍어야 합니다.)

잠시 `Bundling...` 진행 표시가 나온 뒤 앱이 열립니다.

### 연결이 안 될 때

집 공유기가 아니라 회사·학교 와이파이면 기기 간 통신이 막혀 있을 수 있습니다.
터미널에서 `Ctrl+C`로 멈추고:

```bash
npx expo start --tunnel
```

처음 실행 시 추가 설치를 물으면 `y`를 누르세요. 느리지만 어떤 네트워크에서도 연결됩니다.

### A의 한계

- **컴퓨터를 켜 두어야** 폰에서 앱이 돌아갑니다.
- **매일 리포트 알림은 확인할 수 없습니다.** Expo Go 자체 앱으로 뜨고 안드로이드에서 제약이 있습니다.
- 홈 화면 아이콘이 Expo Go 아이콘입니다.

여기까지 잘 되면 **B**로 넘어가세요.

---

## B. EAS 클라우드 빌드 → APK 설치 (권장)

Expo 서버가 대신 빌드해 주고, 완성된 `.apk` 파일을 받아 폰에 설치합니다.
**컴퓨터를 꺼도 돌아가고 알림도 정상 동작합니다.** 안드로이드는 개발자 등록비가 없습니다.

### B-1. Expo 계정 만들기 (무료)

https://expo.dev/signup — 이메일만 있으면 됩니다.

### B-2. 빌드 도구 설치

```bash
npm install -g eas-cli
```

> 맥/리눅스에서 권한 오류가 나면 앞에 `sudo`를 붙이세요.

```bash
eas login
```

방금 만든 계정의 아이디와 비밀번호를 입력합니다. (비밀번호는 화면에 안 보이는 게 정상입니다)

### B-3. 프로젝트 연결

```bash
cd yangpa93/vocab-app
eas init
```

- `Would you like to create a project?` → **y**
- 프로젝트 이름을 물으면 그냥 Enter (기본값 `vocab-app`)

`app.json`에 프로젝트 ID가 자동으로 채워집니다.

### B-4. 빌드 실행

```bash
eas build --platform android --profile preview
```

처음 한 번만 묻는 것들:

- `Generate a new Android Keystore?` → **y**
  (앱 서명 열쇠입니다. Expo가 만들어 보관해 줍니다. **직접 관리할 필요 없습니다.**)

그 다음:

```
✔ Build queued...
🚀 https://expo.dev/accounts/.../builds/xxxx
```

**10~20분** 걸립니다. 터미널을 닫아도 클라우드에서 계속 진행됩니다.
위 링크를 열면 진행 상황이 실시간으로 보입니다.

> 무료 계정은 월 빌드 횟수 제한이 있습니다. 가족용으로는 충분합니다.
> 대기열이 길면 `Waiting in queue`에서 몇 분 더 걸릴 수 있습니다.

### B-5. 폰에 설치

빌드가 끝나면 터미널에 **QR 코드**가 뜹니다.

1. 폰 **기본 카메라 앱**으로 QR을 찍습니다. → 다운로드 페이지가 열립니다.
   (또는 위 `expo.dev` 링크를 카톡으로 자신에게 보내 폰에서 열고 `Install` 버튼)
2. `Install` 을 눌러 `.apk` 를 내려받습니다.
3. 다운로드 알림을 누르면 **"이 출처의 앱은 설치할 수 없습니다"** 경고가 뜹니다.
   → `설정` 버튼 → **"이 출처 허용"** 켜기 → 뒤로 → `설치`
   (스토어를 안 거친 앱이라 나오는 정상 경고입니다)
4. 설치 완료. 홈 화면에 **우리 영단어** 아이콘이 생깁니다.

> **설치가 끝나면 "이 출처 허용"을 다시 꺼 두세요.** 켜 둔 채로 두면
> 나중에 다른 경로로 악성 앱이 설치될 여지가 생깁니다.

### B-6. 요구하는 권한

설치할 때 확인해 보시면 이것뿐입니다.

| 권한 | 왜 필요한가 |
|---|---|
| 알림 | 매일 학습 리포트 |
| 진동 | 정답/오답 피드백 |
| 인터넷 | 🎬 버튼으로 YouGlish 영상 열기 |

저장소 접근, 다른 앱 위에 표시 같은 불필요한 권한은 **명시적으로 차단**해 두었습니다
(`app.json`의 `blockedPermissions`). 카메라·연락처·위치·마이크는 처음부터 요구하지 않습니다.

## C. USB 직접 설치 (Android Studio가 이미 있을 때)

클라우드를 거치지 않고 컴퓨터에서 바로 빌드해 USB로 넣습니다. Expo 계정도 필요 없습니다.
다만 **Android Studio + SDK 설치에 10GB 이상**이 필요합니다.

1. https://developer.android.com/studio 에서 Android Studio 설치
2. 폰에서 **개발자 옵션** 켜기: `설정 → 휴대전화 정보 → 빌드 번호`를 **7번 연속 탭**
3. `설정 → 개발자 옵션 → USB 디버깅` 켜기
4. USB로 연결하고 폰에 뜨는 `USB 디버깅을 허용하시겠습니까?` → **허용**
5. 컴퓨터에서:

```bash
npx expo run:android --variant release
```

첫 빌드는 10~30분 걸립니다. 끝나면 폰에 자동 설치됩니다.

## 설치 후 — 첫 설정

1. 앱을 열면 **프로필 만들기** 화면이 나옵니다.
   이름(별명도 괜찮습니다), 캐릭터, 시작 학년을 고르고 `시작하기`.
   > 지금 학년보다 한 단계 낮게 시작하셔도 됩니다. 다 외우면 자동으로 올라갑니다.

2. 홈 화면 오른쪽 위 **`👨‍👩‍👧 부모님`** → PIN 4자리를 정하고, 한 번 더 입력해 확인합니다.

3. 알림 권한을 묻습니다. → **허용**
   (안드로이드 13 이상에서 이걸 거부하면 리포트 알림이 오지 않습니다.
   나중에 `설정 → 앱 → 우리 영단어 → 알림`에서 켤 수 있습니다.)

4. 부모님 모드 → `설정` 에서 하루 목표(10~20개), 복습 비중, 알림 시각을 조정합니다.

5. 아이가 여러 명이면 홈 화면에서 아이 이름을 눌러 → `+ 아이 추가하기`.

## 알림이 오는지 밤까지 안 기다리고 확인하기

기본 알림 시각이 오후 9시라 그냥 두면 밤에나 알 수 있습니다. 이렇게 하면 몇 분 안에 확인됩니다.

1. 아이 계정으로 **문제를 몇 개 풀어 둡니다** (리포트에 담길 내용이 필요합니다).
2. 폰 시계를 보고, 부모님 모드 → `설정` → **알림 시각을 지금부터 5~10분 뒤**로 맞춥니다.
   (선택지는 오후 6~10시입니다. 지금이 그 시간대가 아니면 폰의 시간대 설정을 잠깐 바꾸거나, 그냥 해당 시간까지 기다리세요.)
3. **홈 화면으로 한 번 나갔다 옵니다.** 알림은 앱이 홈 화면에 올 때 다시 예약되기 때문에 이 단계가 필요합니다.
4. 앱을 완전히 닫고 기다립니다.

이런 알림이 뜨면 정상입니다.

```
📚 오늘의 영단어 학습 리포트
서준 · 오늘 목표 완료! 15개 · 정답률 87% · 3일 연속
```

확인이 끝나면 알림 시각을 원하는 시간으로 되돌리세요.

## 문제가 생기면

**`npm install`에서 빨간 `ERR!` 가 납니다**
Node.js 버전을 먼저 확인하세요(`node --version`, 18 이상). 그래도 안 되면 `vocab-app` 폴더의 `node_modules` 폴더와 `package-lock.json` 파일을 지우고 다시 `npm install`.

**QR을 찍었는데 계속 연결 중입니다**
같은 와이파이인지 확인 → 그래도 안 되면 `npx expo start --tunnel`.

**`eas: command not found`**
`npm install -g eas-cli`가 실패한 것입니다. 맥/리눅스면 `sudo npm install -g eas-cli`.

**`eas build`가 project ID를 찾을 수 없다고 합니다**
`eas init`을 먼저 실행하세요.

**APK를 눌러도 설치가 안 됩니다**
`설정 → 앱 → 특별한 앱 접근 → 알 수 없는 앱 설치` 에서 **크롬**(또는 파일 관리자)에 권한을 주세요.

**앱이 켜지자마자 꺼집니다**
`npm start` 터미널에 빨간 오류가 남아 있을 겁니다. 그 내용을 그대로 알려 주세요.

**🔊 를 눌러도 소리가 안 납니다**
기기에 영어 음성이 필요합니다.
`설정 → 접근성 → 화면 읽기 → 텍스트 음성 변환 출력` → `Google 음성 인식 및 합성` → 언어에 **English (US)** 추가.
음성이 없어도 학습은 그대로 진행됩니다.

**알림이 안 옵니다**
① Expo Go(A 방법)로 실행 중이면 정상입니다 → B로 설치하세요.
② `설정 → 앱 → 우리 영단어 → 알림`이 켜져 있는지 확인.
③ 부모님 모드 → 설정에서 `알림 받기`가 켜져 있는지, 알림 시각이 이미 지났는지 확인.
④ 설정을 바꾼 뒤 **홈 화면에 한 번 다녀와야** 재예약됩니다.
⑤ 삼성·샤오미 등은 배터리 절약이 알림을 막기도 합니다. `설정 → 배터리 → 앱 절전 관리`에서 이 앱을 제외하세요.

**부모 PIN을 잊었습니다**
지금은 초기화 방법이 없습니다. 앱을 지웠다 다시 설치해야 하고, 그러면 **학습 기록도 사라집니다.**
필요하시면 초기화 수단을 넣어 드리겠습니다.
