#
# 표시:  * 중학 기초  |  ** 중학 심화·고1  |  표시 없음 고등·수능
#
# ── 이 목록의 성격 ─────────────────────────────────────────────
# 교육부 「기본 어휘 목록」은 낱개 단어만 싣는다. 숙어는 그 문서에 없다.
# 그래서 이 목록은 **편집 판단**이다 — 중·고 검정 교과서와 수능·모평 지문에
# 되풀이해 나오는 구동사·전치사구·관용표현을 추린 것이고, 교육부 문서에
# 실려 있다는 뜻이 아니다. 그 점을 분명히 해 두려고 파일을 따로 두었다.
#
# **뜻은 지어내지 않는다.** 여기 실린 표제어는 영어 위키낱말사전과 대조해
# 뜻을 확인한 것만 src/data/levels/*.ts 에 들어간다. 사전에 표제어가 없거나
# 뜻이 어긋나면 그 항목은 비워 두고, 데이터에 넣지 않는다.
#
# data/extra-vocabulary.txt 에 이미 있는 숙어 71개는 여기 다시 적지 않는다.
# scripts/build-plan.mjs 가 두 파일을 합칠 때 겹치면 앞의 것을 남긴다.
#
# ── 왜 따로 배치하는가 ─────────────────────────────────────────
# build-plan.mjs 는 단어 목록 전체를 24등분한다. 여기에 숙어를 그냥 합치면
# 이미 자리를 잡은 3,285개가 레벨 사이를 옮겨 다닌다. 아이가 끝낸 레벨의
# 단어가 다음 레벨로 밀려나면 진도가 뒤로 간다. 그래서 숙어는 **기존 배치를
# 건드리지 않고 레벨마다 덧붙인다.**
