앱을 처음 받는 분을 위한 안내입니다. **APK 설치 → 소리 맞추기 → 설정** 순서로
적었습니다.

> 이 앱은 아직 플레이스토어에 없습니다. 그래서 파일(APK)을 직접 받아 깝니다.
> 스토어를 거치지 않는 앱이라 폰이 여러 번 경고를 띄우는데, **그 경고를
> 어떻게 넘기는지**를 1장에 하나하나 적어 두었습니다.

# 1장. APK 깔기 — 경고를 넘기는 법

## 받기

카톡이나 문자로 받은 **링크를 폰 브라우저(삼성 인터넷 · 크롬)로 엽니다.**

> 카톡 안에서 바로 열면 막힐 수 있습니다. 그럴 때는 링크를 길게 눌러
> **[URL 복사]** 한 다음, 브라우저 주소창에 붙여넣으세요.

링크를 열면 파란 **`Install`** 버튼이 나옵니다. 누르면 `.apk` 파일이 받아집니다.

## 경고 ①  "이런 유형의 파일은 기기에 위험할 수 있습니다"

내려받는 중에 뜹니다.

```
  이런 유형의 파일은 기기에 손상을 줄 수 있습니다.
  gomtangivoca.apk 을 계속 다운로드하시겠습니까?

        [ 취소 ]        [ 확인 / 계속 ]
```

👉 **[확인]** 또는 **[계속]** 을 누르세요.

> 안드로이드는 `.apk` 파일이면 내용과 상관없이 무조건 이 경고를 띄웁니다.
> 스토어를 안 거친 파일이라는 뜻이지, 이 앱에 문제가 있다는 뜻이 아닙니다.

## 경고 ②  "이 출처의 앱을 설치할 수 없습니다"

받은 파일을 눌러 설치하려고 하면 뜹니다.

```
  보안상의 이유로 이 출처에서 알 수 없는 앱을
  설치할 수 없도록 차단되어 있습니다.

        [ 취소 ]        [ 설정 ]
```

👉 **[설정]** 을 누르면 스위치 하나가 있는 화면으로 갑니다.

```
  알 수 없는 앱 설치
  Chrome (또는 삼성 인터넷 · 내 파일)

  이 출처의 앱 허용                      [ ○ ← 켜기 ]
```

👉 스위치를 **켜고**, 왼쪽 위 **뒤로 가기(←)** 를 눌러 돌아옵니다. 설치 화면이
그대로 남아 있습니다.

> **이 스위치는 방금 파일을 받은 그 앱에만 켜집니다.** 크롬으로 받았으면
> 크롬에만, 카톡에서 받았으면 카톡에만 켜집니다. 그래서 "분명히 켰는데 또
> 물어본다" 싶으면, 이번에는 **다른 앱으로 파일을 연 것**입니다.

## 경고 ③  "기기 및 개인 정보 보호"

설치를 시작하면 뜹니다.

```
  이 앱은 개발자가 확인되지 않았습니다.
  기기와 개인 정보가 위험해질 수 있습니다.

        [ 자세히 ]   [ 설치 안 함 ]   [ 무시하고 설치 ]
```

👉 **[무시하고 설치]** 를 누르세요.

> 버튼이 안 보이면 **[자세히]** 를 먼저 누르면 나타납니다.
> 기종에 따라 **[그래도 설치]** · **[계속]** 이라고 적혀 있기도 합니다.

## 경고 ④  Play 프로텍트 검사

설치가 끝나갈 때 뜹니다.

```
  Play 프로텍트에서 인식하지 못한 앱입니다.

        [ 자세히 ]        [ 설치 안 함 ]
```

👉 **[자세히]** → **[무시하고 설치]**

> 여기서 **[설치 안 함]** 을 누르면 처음부터 다시 해야 합니다. 헷갈리는
> 자리이니 천천히 보세요 — 우리가 눌러야 하는 것은 늘 **'무시하고'** 쪽입니다.

## 다 됐습니다

`설치됨` 이 뜨면 **[열기]** 를 누르세요. 홈 화면에도 🐻 곰탱이보카 아이콘이
생깁니다.

## ⚠️ 아이콘이 두 개 보인다면

예전 판을 쓰시던 분만 해당합니다. 앱 이름이 바뀌면서 안드로이드가 **다른 앱**
으로 보기 때문에, 예전 것이 지워지지 않고 나란히 남습니다.

1. **예전 앱**을 열고 ⚙️ 설정 → `백업 · 되돌리기` → `백업 파일 내보내기`
   → 공유 창에서 **드라이브** 또는 **Gmail** 을 고릅니다
   (**카카오톡은 안 됩니다** — 받는 쪽에서 못 엽니다)
2. **새 앱**을 열고 ⚙️ 설정 → `백업 · 되돌리기` → `백업 파일 고르기`
   → 방금 올린 파일을 고릅니다
3. 기록이 들어온 것을 확인한 뒤 **예전 앱을 지웁니다**

> 이미 카톡으로 보내 버려서 못 받으시겠다면, 카톡에서 그 파일을 **길게 눌러
> → [다른 앱으로 열기] → 곰탱이보카** 를 고르세요. 앱이 직접 받아 옵니다.

# 2장. 처음 켰을 때

```
        반가워요! 👋
   이 앱을 쓰는 사람이 누구인지 알려 주세요.

   🧒 아이예요        ›
   👨‍👩‍👧 부모예요       ›
```

- **아이 폰이면** `아이예요` → 이름 · 캐릭터 · **시작 학년**을 고릅니다
- **부모 폰이면** `부모예요` → 이름 · 캐릭터만 고릅니다 (학년은 안 묻습니다)

> 시작 학년은 **지금 학년보다 한 단계 낮게** 잡아도 좋습니다. 다 외우면
> 자동으로 올라가고, 처음부터 어려우면 며칠 만에 그만두게 됩니다.

만들고 나면 아이는 아이 화면으로, 부모는 부모 화면으로 갑니다.

# 3장. 소리 맞추기 ①  앱 안에서

**여기부터 하세요.** 폰 설정을 만지지 않고도 대부분 여기서 해결됩니다.

아이 화면 맨 위 오른쪽 **`⚙️ {이름} 설정`** 을 누릅니다.

## 3-1. 소리 켜기

```
🔊 소리로 읽어주기                              [ ●━ ]
영어 문장을 소리로 들려줘요. (English)
```

스위치를 켜면 **그 자리에서 한 번 읽어 줍니다.** 소리가 나는지 바로 알 수
있습니다.

> 괄호 안에 지금 어떤 목소리로 읽는지 적혀 있습니다.

## 3-2. 어떤 목소리로 읽을까요 ★

```
어떤 목소리로 읽을까요
들어 보고 마음에 드는 것을 고르세요. 위에 있는 것이 보통 더 자연스러워요.

┌──────────────────────────┐  ┌────┐
│ English                  │  │ 🔊 │
│ 미국 · 인터넷 필요        │  └────┘
└──────────────────────────┘
┌──────────────────────────┐  ┌────┐
│ English                  │  │ 🔊 │   ← 지금 이것 (테두리가 진합니다)
│ 미국 · 고품질             │  └────┘
└──────────────────────────┘
┌──────────────────────────┐  ┌────┐
│ English                  │  │ 🔊 │
│ 미국                     │  └────┘
└──────────────────────────┘
```

- **🔊 버튼** — 그 목소리로 `Hello! Nice to meet you.` 를 읽어 줍니다.
  **고르기 전에 들어 보세요.**
- **줄을 누르면** 그 목소리로 바뀝니다. 테두리가 진해집니다.

**위에서부터 하나씩 눌러 보고 가장 자연스러운 것을 고르시면 됩니다.**

| 표시 | 뜻 |
|---|---|
| `인터넷 필요` | 와이파이·데이터가 있어야 소리가 납니다. **보통 이게 가장 자연스럽습니다** |
| `고품질` | 폰에 받아 둔 좋은 음성입니다. 인터넷 없이도 됩니다 |
| (아무것도 없음) | 폰에 기본으로 들어 있는 음성입니다. 조금 딱딱합니다 |

> **지하철·차 안에서 많이 쓰신다면** `인터넷 필요` 가 없는 것 중에 `고품질`
> 이 붙은 것을 고르세요. 그런 것이 없으면 4장으로 가서 받으시면 됩니다.

## 3-3. 읽는 속도 ★

```
읽는 속도
폰 설정이 아니라 여기서 정합니다. 고르면 바로 들려줘요.

  [ 느리게 ]   [ 보통 ]   [ 빠르게 ]
```

누르면 **그 속도로 바로 읽어 줍니다.** 아이에게 들려주고 고르세요.

> ⚠️ **폰 설정(4장)의 '말하는 속도' 는 이 앱에 안 먹습니다.** 앱이 속도를
> 직접 정하고 있어서요. 속도는 반드시 **여기서** 바꾸셔야 합니다.
> (톤은 반대로 폰 설정에서 바꾸셔야 합니다 — 아래 4장)

## 3-4. 소리가 아예 안 날 때

```
⚠️ 영어 목소리가 이 기기에 없어요
그래서 영어는 소리로 안 읽어 줍니다. 한국어 목소리로 영어를 읽으면
발음이 잘못 들려서, 차라리 조용히 두었어요.
```

이 노란 상자가 뜨면 폰에 **영어 음성이 하나도 없는 것**입니다. 4장으로 가세요.

> 일부러 조용하게 둔 것입니다. 한국어 엔진이 영어를 읽으면 `beautiful` 이
> **'베아우티풀'** 로 나오는데, 오류도 안 나고 소리는 나오니 고장인 줄도
> 모른 채 아이가 그 발음을 외우게 됩니다.

# 4장. 소리 맞추기 ②  폰 설정에서 (삼성)

3장으로 안 되거나, **더 좋은 음성을 받고 싶을 때** 하시면 됩니다.

## 4-1. 삼성 폰 — 엔진 바꾸고 음성 받기

```
설정 → 접근성 → TalkBack → 설정 → 글자 읽어 주기
   → 기본 엔진 → [ Google 음성 인식 및 합성 ] 선택
   → 앞 화면으로 돌아가서
   → 언어 → [ 영어(미국) ] 선택
   → 아래 말하는 속도 · 목소리 톤 조정
```

> **`Google 음성 인식 및 합성` 을 고르는 것이 핵심입니다.** 삼성 폰은 기본이
> `삼성 TTS` 인데 영어가 특히 딱딱합니다. 이것만 바꿔도 크게 달라집니다.

**One UI 버전에 따라 길이 다를 수 있습니다.** 위 경로에 `글자 읽어 주기` 가
없으면 이쪽으로 가 보세요 — 같은 화면에 닿습니다.

```
설정 → 접근성 → 음성으로 읽어주기 → 글자 읽어 주기(TTS)
```

찾기 어려우면 **설정 맨 위 돋보기에 `글자 읽어` 라고 쳐 보세요.**

## 4-2. 조정하는 두 가지

| 무엇 | 어디서 | 이 앱에 먹히나 |
|---|---|---|
| **말하는 속도** | 폰 설정 | ❌ **안 먹습니다.** 앱의 `읽는 속도`(3-3)에서 바꾸세요 |
| **목소리 톤** | 폰 설정 | ✅ **먹습니다.** 여기서 낮추면 앱에서도 낮아집니다 |

> 왜 다르냐면 — 앱이 읽을 때마다 **속도는 직접 지정**하고 **톤은 지정하지
> 않기** 때문입니다. 그래서 톤만 폰 설정을 따라갑니다.
>
> 폰 설정의 미리듣기에서는 속도가 바뀌니 "됐다" 싶은데 앱에서는 그대로입니다.
> 헷갈리기 쉬운 자리라 적어 둡니다.

## 4-3. 좋은 영어 음성 받기

같은 화면에서:

```
기본 엔진 옆 [ ⚙️ 톱니바퀴 ] → 음성 데이터 설치
   → English (United States)
   → 목록에서 마음에 드는 음성을 받습니다 (⬇️ 표시)
```

받고 나면 **앱을 완전히 껐다 켜세요.** 그래야 새 음성이 3-2 목록에 나타납니다.

## 4-4. 아이폰

```
설정 → 손쉬운 사용 → 음성 콘텐츠 → 음성 → English
   → 원하는 음성 옆 ⬇️ 를 눌러 받습니다
```

# 5장. 아이 설정 — 무엇을 어디서 바꾸나

아이 화면 맨 위 오른쪽 **`⚙️ {이름} 설정`**

| 항목 | 무엇 |
|---|---|
| **무엇부터 풀까요** | 영어 먼저 / 국어 먼저 (두 과목을 다 켠 아이만 나옵니다) |
| **하루에 새로 배울 단어** | 5 ~ 20개. 아래에 `오늘 몇 문제, 약 몇 분` 이 나옵니다 |
| **🔊 소리로 읽어주기** | 켜고 끄기 |
| **어떤 목소리로 읽을까요** | 3-2 |
| **읽는 속도** | 3-3 |
| **📳 진동 피드백** | 맞히거나 틀렸을 때 살짝 떨림 |
| **내 캐릭터** | 12간지 + 그 밖에. 바꿔도 기록은 그대로 |
| **👨‍👩‍👧 부모님과 연결하기** | 6장 |
| **💾 공부 기록 지키기** | 7장 |

> **하루 분량은 아이가 직접 고릅니다.** 스스로 정한 속도라야 "계획보다 빨리
> 끝냈다"가 자기 성과가 됩니다. 복습 개수와 학년·레벨은 부모님이 정합니다.

## 부모님 모드로 들어가려면

아이 설정 **맨 아래** `👨‍👩‍👧 부모님 모드` 를 누릅니다. PIN 이 걸려 있어
아이는 못 들어갑니다.

# 6장. 부모 설정

부모 화면 맨 위 오른쪽 **`⚙️ 설정`** → 세 갈래가 나옵니다.

```
👧 아이들 폰 설정                                        ›
   아이 2명 · 연결 · 매일 리포트 알림 · 기본 요청권 금액 · 백업 · PIN

📚 내 공부 설정                                          ›
   일상 문장 5개 · 국어 5개

🔊 소리와 목소리                                         ›
   Google 미국 영어 · 보통 읽기 · 들어보고 바꾸기
```

세 번째 줄에 **지금 어느 목소리로 얼마나 빠르게 읽는지** 그대로 적혀
있습니다. 눌러 들어가지 않아도 보입니다.

## 6-1. 아이 폰과 연결하기

`아이들 폰 설정` → `🔗 아이 기기와 연결하기`. 두 가지 중 **편한 쪽 하나만**
하시면 됩니다.

```
1. 아이폰에서 생성한 QR를 내폰에서 찍어 연결하기
   아이 폰: ⚙️ 설정 → 부모님과 연결하기 → 📱 내 QR 띄우기
   부모 폰: [ 📷 아이 QR 찍기 ]

2. 내 폰에서 생성한 QR을 아이폰에서 찍어 연결하기
   부모 폰: [ 📱 내 QR 띄우기 ]
   아이 폰: ⚙️ 설정 → QR 찍기
```

### 찍었는데 아무 일도 안 일어난다면

QR 을 네모 안에 맞췄는데 화면이 조용하면, 이제는 **왜 안 되는지 화면에
적힙니다.** 거기 적힌 내용을 보고 갈라집니다.

| 화면에 뜨는 말 | 무슨 뜻인가 | 무엇을 하나 |
|---|---|---|
| `이 QR 은 곰탱이보카 것이 아니에요` + 읽은 내용 | 다른 QR 을 찍었습니다 | 아이 폰에서 **📱 내 QR 띄우기** 를 눌러 뜬 QR 을 찍으세요 |
| `이 기기의 QR 이에요` | 내 폰 화면을 찍었습니다 | 상대 폰 화면을 찍으세요 |
| `자리가 다 찼어요` | 아이가 이미 4명입니다 | 한 명을 지우고 다시 찍으세요 |
| `연결하다 막혔어요` | 알림 권한이나 인터넷에서 걸렸습니다 | 그대로 한 번 더 찍으세요 |
| 아무 말도 없다 | 카메라가 QR 을 아직 못 읽었습니다 | 폰을 20cm 쯤 띄우고 화면 밝기를 올리세요 |

> **두 폰의 판이 달라도 됩니다.** 아이 폰에 지난달 앱이 깔려 있어도 그 QR 을
> 읽습니다(0.18.0 부터).

### 카메라가 안 될 때 — 코드로 연결하기

카메라가 고장 났거나 권한이 막혔으면 코드로 합니다.

```
아이 폰: ⚙️ 설정 → 부모님과 연결하기 → 📱 내 QR 띄우기
         QR 아래 '카메라가 안 되면 이 코드를 불러 주세요' 밑의 글자
부모 폰: ⚙️ 설정 → 아이들 폰 설정 → 🔗 아이 기기와 연결하기
         → [ 📵 카메라가 안 되면 — 코드로 연결하기 ]
         코드와 아이 이름을 적고 [ 연결하기 ]
```

대문자와 소문자를 구별해서 적어야 합니다. 아이 이름은 목록에서 누가 누구인지
가리는 데 쓰니 꼭 적어 주세요.

- 아이는 **4명까지** 연결됩니다. 지금 몇 명인지 제목 옆에 `2 / 4명` 으로 나옵니다.
- **엄마 폰과 아빠 폰이 함께 받을 수 있습니다.** 아이 폰 한 대에 부모 폰을
  3대까지 잇습니다. 아빠가 찍어도 엄마 폰이 안 밀립니다.
- 동기 부여 요청권은 **주 부모 한 분**에게만 갑니다. 누구로 할지는 아이
  ⚙️ 설정 → `부모님과 연결됨` 에서 눌러 바꿉니다.

## 6-2. 기본 동기 부여 요청권 금액

아이가 레벨 시험에 통과하거나 한 달을 개근하면 요청할 수 있는 금액입니다.

- 눌러서 고르는 금액은 **중학교 3만원 · 고등학교 5만원**까지입니다
- 맨 끝 **`기타`** 를 누르면 빈칸이 나와 직접 적을 수 있습니다
- `안 함`(0원) 으로 두면 그 요청권은 아예 안 생깁니다
- 아이마다 다르게 두려면 **아이들 학습 보고서 → 그 아이** 에서 정합니다

## 6-3. 내 공부 설정

부모님도 같이 공부하실 수 있습니다. 세 갈래 중 고르시고, **갈래마다 하루 몇
개인지 따로** 정합니다.

```
일상 생활 문장 학습하기      [5개] [10개]   + 주제 8가지 중 하나
아이들과 같은 영어 단어      [5개] [10개]   + 아이와 같은 레벨
국어 어휘 학습하기           [5개] [10개]   + 레벨
```

**하나도 안 고르시면** 부모 홈에 `아이들 학습 보고서` 만 나옵니다. 공부는
안 하고 아이 기록만 보시겠다는 뜻으로 받습니다.

## 6-4. 소리와 목소리 ★

부모님도 일상 문장과 영어 단어를 **소리로 듣습니다.** 그래서 부모 설정에도
목소리를 들어 보고 고르는 자리를 두었습니다.

`⚙️ 설정` → `🔊 소리와 목소리`

내용은 **3장과 똑같습니다** — 소리 켜기 · 어떤 목소리로 읽을까요(줄마다 🔊
로 미리 들어 보기) · 읽는 속도. 3장을 그대로 따라 하시면 됩니다.

한 가지만 다릅니다.

> **여기서 고른 것은 이 폰의 부모님 것입니다.**
> 아이 폰의 목소리는 **그 폰에서** 아이가 직접 골라야 합니다
> (`내 학습 기록 및 설정` → 3장). 부모 폰에서 고쳐도 아이 폰은 안 바뀝니다.
> 알맞은 속도는 아이마다 다르니, 아이가 직접 들어 보고 고르는 편이 낫습니다.

# 7장. 폰을 바꿀 때 — 백업

기록은 **그 폰 안에만** 있습니다. 서버에 안 올라갑니다. 폰을 바꾸거나 앱을
지우면 사라지니 한 달에 한 번쯤 빼 두세요.

## 저장하기

```
⚙️ 설정 → 💾 공부 기록 지키기 → 백업 · 되돌리기
   → [ 💾 파일로 저장하기 ]
   → 폴더를 고르는 창이 뜹니다 → '다운로드' 선택
```

> **카카오톡으로 보내지 마세요.** 받는 쪽에서 "파일을 열 수 있는 앱이 없다"며
> 못 내려받습니다. 드라이브나 메일은 잘 갑니다.

## 되돌리기

```
새 폰의 앱 → ⚙️ 설정 → 백업 · 되돌리기 → [ 백업 파일 고르기 ]
   → 저장해 둔 파일 선택
   → 무엇이 들어 있는지 먼저 보여줍니다
   → 확인하고 '통째로' 또는 '아이만' 을 고릅니다
```

되돌리기는 되돌릴 수 없어서, **내용을 먼저 보여드리고** 그다음에 고르게 합니다.
