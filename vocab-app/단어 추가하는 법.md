# 단어·숙어 추가하는 법

앞으로 어휘를 더 넣고 싶을 때 보는 문서입니다.
**명령은 하나뿐입니다.**

```powershell
npm run data:update
```

앱을 폰까지 가져가는 절차는 [소스 파일 수정 후 수행 프로세스.md](./소스%20파일%20수정%20후%20수행%20프로세스.md)
에 있습니다. 여기는 **어휘 데이터만** 다룹니다.

---

## 0장. 먼저 알아 둘 것 하나

### 이미 배운 단어는 절대 레벨이 안 바뀝니다

이게 이 구조에서 가장 중요합니다.

예전에는 단어 목록 전체를 그때그때 24등분했습니다. 그래서 단어를 **하나만
더 넣어도** 경계가 한 칸씩 밀려 수십 개가 다른 레벨로 옮겨 갔습니다.
그러면 이런 일이 생깁니다.

- 아이가 이미 끝낸 레벨에 새 단어가 생겨 레벨 시험을 다시 봐야 하고
- 아직 안 배운 단어가 지나간 레벨로 밀려 영영 안 나오고
- 레벨 시험 문항 수가 통째로 달라집니다

지금은 자리를 **`data/placement.json`** 에 못박아 둡니다. 거기 적힌 단어는
무슨 일이 있어도 그 레벨에 남습니다. **새로 들어온 단어만** 자리를 찾습니다.

새 단어는 난이도 층이 맡은 구간에서 **가장 홀쭉한 레벨**로 갑니다.

| 층 | 표시 | 들어가는 레벨 |
|---|---|---|
| 기초 (초등 권장) | `단어*` | 중1-1 … 중2-4 |
| 중급 (중학 권장) | `단어**` | 중3-1 … 고1-4 |
| 고급 (고등) | `단어` (표시 없음) | 고2-1 … 고3-4 |

`placement.json` 은 **저장소에 같이 올립니다.** 자리가 언제 어떻게 정해졌는지가
이력에 남아야 하기 때문입니다. 손으로 고치지 마세요.

---

## 1장. 단어를 더 넣기

### 1단계 — 목록에 표제어를 적습니다

셋 중 맞는 파일에 한 줄씩 적습니다. 알파벳 순서를 맞출 필요 없습니다.

| 파일 | 무엇을 적나 |
|---|---|
| `data/official-basic-vocabulary.txt` | 교육부 「기본 어휘 목록」에 있는 것 |
| `data/extra-vocabulary.txt` | 교과서·시험에 자주 나오는 파생어 |
| `data/idiom-vocabulary.txt` | 숙어 (구동사·전치사구·관용표현) |

난이도 표시를 꼭 붙입니다. 이게 레벨을 정합니다.

```
resilient**
take a rain check
```

### 2단계 — 뜻과 예문을 적습니다

`data/batch-이름.txt` 로 새 파일을 만듭니다. 이름은 아무거나 좋습니다
(`batch-2026봄.txt` 처럼). `batch-` 로 시작하고 `.txt` 로 끝나면 자동으로 읽힙니다.

한 줄에 뜻 하나입니다. 칸은 `|` 로, 예문은 영어와 해석을 `::` 로 나눕니다.

```
표제어|품사|뜻|유의어;유의어|영어::해석|영어::해석|영어::해석
```

실제 예:

```
resilient|adj.|회복력 있는, 잘 견디는|tough;strong|Children are surprisingly resilient.::아이들은 놀랄 만큼 잘 견딘다.|The economy proved resilient.::경제는 회복력이 있는 것으로 드러났다.|She has a resilient spirit.::그녀는 잘 꺾이지 않는 마음을 지녔다.
take a rain check|phr.|다음으로 미루다||Can I take a rain check on dinner?::저녁은 다음으로 미뤄도 될까요?|He took a rain check and left early.::그는 다음을 기약하고 일찍 떠났다.|Let's take a rain check until next week.::다음 주로 미루자.
```

규칙은 다섯 가지입니다.

1. **예문은 3개 이상.** 라운드마다 다른 문장이 나와야 하기 때문입니다.
2. **예문에 표제어가 실제로 들어 있어야** 빈칸 문제를 낼 수 있습니다.
   `resilient` 를 묻는데 예문에 `resilience` 만 있으면 빈칸을 못 만듭니다.
3. **숙어의 품사는 `phr.`** 로 통일합니다.
4. **다의어는 같은 표제어를 여러 줄**에 적습니다. 적은 순서대로 뜻이 쌓입니다.
5. 유의어가 없으면 그 칸을 비워 둡니다 (`|` 두 개를 붙여 씁니다).

### 3단계 — 한 줄 명령

```powershell
npm run data:update
```

이게 순서대로 다 합니다.

1. 배치표를 다시 만들고 (`data/*.txt` → `src/data/plan.ts`)
2. `data/batch-*.txt` 를 전부 수록하고 (`src/data/levels/*.ts`)
3. 아직 빈 자리를 알려 주고
4. 데이터 검사를 돌립니다

**여러 번 돌려도 안전합니다.** 이미 수록된 표제어는 건너뜁니다. 중간에
멈췄으면 그냥 다시 부르면 됩니다.

### 4단계 — 전체 검사

```powershell
npx tsc --noEmit
npx jest
```

둘 다 통과하면 끝입니다. 커밋하고 올리세요.

## 2장. 뜻이 맞는지 확인하기

**지어낸 뜻은 넣지 않습니다.** 아이는 그 뜻이 맞다고 믿고 외웁니다.

### 낱개 단어

영어 위키낱말사전과 대조합니다. 유의어가 한 군데도 안 겹치면 사람이 볼
목록에 올라옵니다. 자동으로 고치지는 않습니다.

```powershell
npm run reference reference.json     # 한 번 만들어 두고 (3GB를 흘려보냅니다)
npm run verify:meaning reference.json
```

### 숙어

숙어는 사전에 유의어가 거의 안 달려 있어 위 방법이 안 통합니다. 대신
**우리 뜻과 사전 뜻을 나란히 찍어** 사람이 보게 합니다.

```powershell
npm run data:idioms
```

- 구 자체가 사전 표제어면 그 뜻을 보여줍니다
- 사전이 구로 싣지 않는 것(`refer to`, `adhere to` 처럼 뜻이 낱말에서
  그대로 읽히는 것)은 **핵심 낱말**의 뜻으로 되짚고 `(핵심 낱말로 확인)`
  이라고 표시합니다
- 어느 쪽으로도 확인이 안 되면 **오류로 세웁니다.** 그런 표제어는 데이터에
  넣지 않습니다

### 모양 검사

```powershell
curl -sLO https://raw.githubusercontent.com/dwyl/english-words/master/words_alpha.txt
npm run audit words_alpha.txt
```

철자·마침표·한글 섞임 같은 것을 봅니다.

## 3장. 국어 어휘를 더 넣기

영어와 길이 다릅니다. 국어는 **뜻과 예문을 사전에서 받아 옵니다.**
지어내지 않습니다.

```powershell
$env:STDICT_KEY = "발급받은 인증키"
node scripts/korean/stdict-examples.mjs     # 표준국어대사전 용례
node scripts/korean/opendict-examples.mjs   # 우리말샘 용례
node scripts/korean/build-levels.mjs        # 레벨 파일로 굽기
```

인증키는 [표준국어대사전 오픈 API](https://stdict.korean.go.kr/openapi/openApiInfo.do)
에서 무료로 받습니다. **키를 파일에 적지 마세요.** 환경 변수로만 넘깁니다
(`.gitignore` 가 막고 있지만 실수는 늘 생깁니다).

지금 남아 있는 것:

- **수능 어휘 55개** — 후보에는 있는데 사전에서 용례를 못 받아 레벨에 못
  들어갔습니다. 위 명령을 키와 함께 돌리면 채워집니다.
- **고전 145개 중 원문 인용은 12개** — 나머지는 위키문헌에 본문이 없거나
  (속미인곡 등), 원문에 띄어쓰기가 없어(송강가사) 문장을 끊을 수 없습니다.

## 4장. 부모님용 일상 문장

`korean/english_365_dataset.json` 에서 굽습니다.

```powershell
node scripts/build-daily.mjs
```

**원본 파일은 365일치가 아닙니다.** 8개 주제 × 10문장 = 80문장을 45~46번씩
되풀이해 365일을 채워 놓은 것이라, 실제로 서로 다른 문장은 80개뿐입니다.
문장을 더 넣고 싶으면 그 파일에 주제를 더하거나 문장을 더한 뒤 위 명령을
다시 부르면 됩니다. `src/data/daily/phrases.ts` 는 **손으로 고치지 마세요** —
다음 번에 덮어써집니다.

## 5장. 막혔을 때

| 이렇게 나오면 | 뜻 | 할 일 |
|---|---|---|
| `배치표에 없는 단어 N개` | 1단계를 빼먹었습니다 | 목록 파일에 표제어를 적고 다시 |
| `이미 있어 건너뜀` | 그 표제어는 이미 수록돼 있습니다 | 그냥 두면 됩니다 |
| `예문이 N개뿐입니다` | 3개가 안 됩니다 | 배치 파일에 예문을 더 적습니다 |
| `예문에 표제어가 없다` | 빈칸을 못 만듭니다 | 표제어가 그대로 들어간 문장으로 바꿉니다 |
| `사전에 없는 표제어` | 뜻을 확인할 길이 없습니다 | 그 표제어를 뺍니다 |
| 레벨당 개수가 160을 넘음 | 레벨 시험이 너무 길어집니다 | 더 넣지 말거나 레벨을 쪼갭니다 |

|---|---|

| 영어 숙어 | 476 |

레벨을 24개보다 더 잘게 쪼개야 합니다. 그건 진도와 보상이 다 얽혀 있어
따로 이야기해야 합니다.
