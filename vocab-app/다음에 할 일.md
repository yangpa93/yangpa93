### 아직 안 넣은 14개 — **자리가 모자랍니다** ★

뜻에 자국이 남았던 13개는 이제 표가 깨끗해져 넣을 수 있게 됐습니다.
그런데 **넣을 자리가 3개뿐입니다.**

```
기초 8레벨   1249 / 상한 1280   → 31 자리
중급 8레벨   1278 / 상한 1280   →  2 자리
고급 8레벨   1279 / 상한 1280   →  1 자리
```

13개는 `arrangement` · `narrative` · `exclaim` · `exclusively` ·
`refer to ~ as ...` · `ritual` · `appearance` · `arena` · `association` ·
`distinction` · `trade-off` · `signature` · `ongoing` 입니다. 수능 어휘라
대부분 중급·고급이 맞는데, 그 두 층이 다 찼습니다.

**고르실 것 —**

1. **기초 층에 넣는다.** `appearance` · `arena` · `association` · `exclaim` ·
   `signature` 정도는 중학교 수준으로 볼 수 있습니다. 나머지 여덟은 무리입니다.
2. **레벨당 상한 160을 올린다.** 지금 선은 "시험 문항이 160 안팎, 30분" 입니다.
   170으로 올리면 레벨 시험이 5분쯤 길어집니다.
3. **레벨을 하나 더 쪼갠다.** 24 → 25레벨. 진도 표시가 전부 바뀝니다.

저는 **2번**을 권합니다. 어차피 앞으로도 낱말은 늘어날 텐데, 지금 상한이면
스물몇 개밖에 더 못 넣습니다.

`take ~ for granted` 는 앱에 이미 `take for granted` 가 있어 넣지 않았습니다.
물결만 다른 같은 표현이라 **같은 낱말이 둘**이 됩니다.

### 알아 둘 것

- `npm run export` 는 **손보신 표를 덮어쓰기 전에 옆에 치워 둡니다**
  (`국어-어휘.손본것-20260805-1030.csv`). 반나절 들인 파일이 사라지지 않습니다.
- 엑셀은 `scripts/xlsx-sheet-to-csv.py` **한 곳에서만** 읽습니다.
- 낱말 하나가 **다섯 곳**에 걸쳐 있습니다 — levels/*.ts · plan.ts ·
  placement.json · antonyms.ts · spelling.ts. `apply-english` 가 다 치웁니다.
- 교육부 원본 목록(`data/*.txt`)은 **손대지 않습니다.** 안 가르칠 것은
  `data/not-taught.json` 에.  국어 교정은 `korean/corrections.json` 에.
- **창에서는 한글이 깨져 보입니다.** 검사 결과는 `--out=` 으로 파일에 뽑아 보세요.
- **낱말을 더하거나 빼면 `npm run bump-data` 로 어휘 판도 올리세요.**
  안 올리면 `npm test` 가 개수가 안 맞는다고 잡습니다.
- **`git checkout src/data/levels/` 를 조심하세요.** 아직 커밋 안 한 낱말이
  통째로 날아갑니다. 실제로 한 번 224개를 날렸습니다(batch 파일이 남아 있어
  `add-entries` 로 다시 쌓았습니다). 되돌리기 전에 커밋부터 하세요.
- **`> plan.ts 2>&1` 로 쓰지 마세요.** build-plan 은 진행 상황을 stderr 로

## 이번에 고친 것

**도구 둘을 새로 만들었습니다.**

- `npm run check-meanings` — 뜻에 남은 줄바꿈 자국을 찾는다. 네 가지 모양을
  본다(홀로 못 쓰는 조각 · 한 글자가 떠 있음 · 괄호 옆이 벌어짐 · 쉼표 뒤가
  붙음). **못 잡는 것도 있습니다** — 「0개」 가 다 맞다는 뜻은 아닙니다.
- `npm run apply-meanings` — 표의 뜻을 앱에 갈아 끼운다. 넣기 전에 위 검사를
  먼저 돌려, **자국이 하나라도 남아 있으면 아무것도 안 하고 멈춥니다.**
  뜻이 여럿인 낱말은 건드리지 않고 목록으로 보여 줍니다. 긴 뜻은 앞 다섯
  개만 남깁니다(`--keep=N` · 안 자르려면 `--keep=0`).
- `node scripts/move-level.mjs <낱말>=<학년>` — 낱말을 다른 레벨로 옮긴다.
  배치표 · placement.json · 레벨 파일 **세 곳을 한 번에** 맞춥니다.
- `python scripts/batch-to-xlsx.py` — 넣은 낱말을 엑셀 한 장으로 뽑는다.
  마크다운으로는 한 화면에 몇 개밖에 안 들어와 224개를 훑기 어려웠습니다.

**조용히 어긋나던 것 둘을 고쳤습니다.**

- `npm run bump-data` 가 **판 번호만 올리고 목록에는 새 줄을 안 넣었습니다.**
  이 저장소의 `.ts` 는 CRLF 인데 도구가 `'…[\n'` 으로 찾고 있었습니다.
  줄 끝을 파일에서 알아보게 고쳤고, 못 찾으면 멈추게 했습니다.
- `npm run e2e` 의 「낱말 개수가 함께 나온다」 가 **`영어 3690개` 를 박아 두고
  있었습니다.** 초등 낱말 108개를 뺐을 때 3582 가 되면서 그 줄만 빨개져
  있었습니다(137개 중 136개 통과였습니다). 어휘 판에서 읽어 오게 고쳤습니다.

**e2e 를 돌리실 때** — 낱말을 고친 뒤에는 `npm run preview` 를 **다시**
켜세요. 미리보기는 구워 둔 것을 내놓기 때문에, 켜 둔 채로 데이터를 고치면
옛 낱말 수가 그대로 나와 이 검사가 빨개집니다. 실제로 한 번 그랬습니다.
