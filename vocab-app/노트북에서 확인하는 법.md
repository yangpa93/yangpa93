# 노트북에서 확인하는 법

폰에 APK 를 깔지 않고, **노트북 브라우저로 앱을 눌러 보는** 방법입니다.

APK 를 만들어 폰에 옮겨 까는 데 20분이 걸립니다. 화면 하나 확인하자고 그걸
매번 하실 수는 없습니다. 웹으로 띄우면 **1분** 만에 같은 화면을 눌러 보실 수
있습니다.

컴퓨터는 **윈도우 PowerShell** 기준입니다.

# 0장. 딱 세 줄 요약

```powershell
cd C:\MyDirectory\yangpa93\vocab-app     # 폴더로 들어가서
git pull origin claude/voca-meaning-review-kzo48f    # 최신 받고
npm run whats-in                          # 제대로 받아졌나 확인하고
npm run preview                           # 브라우저로 띄웁니다
```

마지막 명령이 주소를 알려 줍니다. 브라우저에서 그 주소를 열면 끝입니다.

> 폴더 경로(`C:\MyDirectory\...`)는 회원님 컴퓨터에 맞게 바꾸세요.
> 모르시면 파일 탐색기에서 `vocab-app` 폴더를 열고 주소창을 복사하시면 됩니다.

# 1장. 처음 한 번만 — 준비

이 장은 **한 번만** 하시면 됩니다. 다음부터는 2장부터 시작하세요.

## 노드(Node.js)가 깔려 있어야 합니다

PowerShell 을 열고 쳐 보세요.

```powershell
node -v
```

`v20.x` 나 `v22.x` 처럼 나오면 됐습니다. `인식할 수 없는 이름` 이라고 나오면
[nodejs.org](https://nodejs.org) 에서 **LTS** 판을 받아 까시고, **PowerShell 창을
닫았다 새로 여세요.** (새 창을 안 열면 방금 깐 것을 못 찾습니다.)

## 꾸러미 받기

`vocab-app` 폴더로 들어가서 한 번 부릅니다. 몇 분 걸리고, 인터넷을 씁니다.

```powershell
cd C:\MyDirectory\yangpa93\vocab-app
npm install
```

`added 800 packages` 같은 말이 나오면 됐습니다.

> **`node_modules` 폴더는 깃허브에 없습니다.** 그래서 `git pull` 로는 안 받아지고
> `npm install` 을 따로 해야 합니다. 나중에 제가 새 꾸러미를 더하면 그때
> 한 번 더 부르시면 됩니다.

# 2장. 최신 받아 오기 (git pull)

```powershell
cd C:\MyDirectory\yangpa93\vocab-app
git pull origin claude/voca-meaning-review-kzo48f
```

이렇게 나오면 잘 받아진 것입니다.

```
Updating 1d5e0ab..a1b2c3d
Fast-forward
 vocab-app/app/parent-home.tsx | 180 ++++++++++++++
 ...
 12 files changed, 900 insertions(+)
```

`Already up to date.` 는 **이미 최신** 이라는 뜻입니다. 이것도 정상입니다.

## 줄기(브랜치) 이름을 잊으셨으면

```powershell
git branch -r
```

`origin/claude/...` 로 시작하는 줄들이 나옵니다. 제가 작업한 것은 지금
`claude/voca-meaning-review-kzo48f` 입니다.

## `git pull` 이 거부당하면

`Your local changes would be overwritten` 이라고 나오면, 회원님 컴퓨터에서
파일을 고치신 것이 있다는 뜻입니다. 고친 것을 버려도 괜찮으면:

```powershell
git checkout -- .
git pull origin claude/voca-meaning-review-kzo48f
```

버리면 안 되는 것이면 저에게 말씀해 주세요.

# 4장. 노트북에서 앱 띄우기

```powershell
npm run preview
```

맨 윗줄에 **`> gomtangivoca@1.0.0 preview`** 라고 나옵니다. 예전에는 여기가
`uri-vocab` 이었습니다 — 그것이 보이면 아직 예전 소스입니다.

처음에는 웹으로 굽느라 **1~2분** 걸립니다. 다 되면 이렇게 나옵니다.

```
────────────────────────────────────────────
  준비됐습니다. 브라우저에서 아래 주소를 여세요.

      http://localhost:8088/demo/

  거기서 보고 싶은 상황을 고르면 앱으로 넘어갑니다.
  끝내려면 이 창에서 Ctrl+C 를 누르세요.
────────────────────────────────────────────
```

**브라우저를 열고 `http://localhost:8088/demo/` 를 치세요.**

## 상황을 고르는 화면

거기에 버튼이 여섯 개 있습니다. 누르면 그 상황이 심어지고 앱이 열립니다.

| 버튼 | 무엇을 보나 |
|---|---|
| 🆕 아무것도 없는 상태 | 설치 직후. 아이/부모 고르는 첫 화면 |
| 🦊 아이 — 아직 연결 안 됨 | 홈에 '부모님과 연결하기'가 뜬 아이 화면 |
| 🦊 아이 — 연결됨 | 연결 안내가 사라진 기존 그대로의 아이 화면 |
| 🦊 아이 — 숙어가 복습으로 | 공부 시작하면 첫 문제부터 숙어가 나옴 |
| 👩‍💼 부모 — 아이 둘 등록됨 | 부모 홈 세 갈래, 아이 보고서까지 |
| 👩‍💼 부모 — 아직 안 고름 | '무엇을 공부할지 정하기'부터 |

## 영어 소리도 여기서 들어 보실 수 있습니다

같은 페이지 맨 아래 **`4. 영어 소리 들어보기`** 가 있습니다. **스피커를 켜고**
버튼을 눌러 보세요.

- 앱이 **어느 목소리를 골랐는지** 이름과 언어가 나옵니다
- `🔊 문장 듣기` — 실제로 문제에서 읽어 주는 속도 그대로
- `🔊 낱말 듣기` — 낱말 하나는 더 느리게 읽습니다
- `⚠️ 한국어 목소리로 읽으면` — **예전에 왜 이상했는지** 들어 보실 수 있습니다

브라우저가 쓰는 목소리는 윈도우에 깔린 것이라 폰과 똑같지는 않지만,
**고르는 규칙은 앱과 같습니다.**

**다른 상황을 보고 싶으면 `/demo/` 로 돌아가 다른 버튼을 누르시면 됩니다.**
누를 때마다 이전 상태는 지워집니다.

## 폰 크기로 보기

브라우저에서 `F12` → 왼쪽 위 📱 아이콘을 누르면 폰 화면 크기가 됩니다.
`Ctrl` + `Shift` + `M` 으로도 됩니다. 실제 폰에서 보이는 모습에 가깝습니다.

## 두 번째부터는 더 빠르게

소스를 안 고쳤으면 굽는 단계를 건너뛸 수 있습니다.

```powershell
npm run preview -- --fast
```

**소스를 고친 뒤에는 `--fast` 없이** 부르셔야 고친 것이 반영됩니다.

## 끝낼 때

명령을 띄운 PowerShell 창에서 `Ctrl` + `C` 를 누르세요.

# 5장. 무엇을 눌러 봐야 하나 — 확인 목록

주신 피드백 순서대로 적었습니다. 하나씩 눌러 보시면 됩니다.

## ① 첫 화면에서 아이/부모 고르기

`🆕 아무것도 없는 상태` → 앱이 열립니다.

- [ ] `반가워요! 👋` 아래에 **아이예요 / 부모예요** 두 개가 보입니다
- [ ] `아이예요` 를 누르면 이름·캐릭터·**시작 학년**을 묻습니다
- [ ] 위쪽 `바꾸기` 를 눌러 되돌아가서 `부모예요` 를 누르면 **학년을 안 묻습니다**
- [ ] 부모로 만들면 부모 홈으로, 아이로 만들면 아이 홈으로 갑니다

## ② 아이가 QR 을 만들고, 연결 안 함은 부모가 승인

`🦊 아이 — 아직 연결 안 됨`

- [ ] 홈에 **`👨‍👩‍👧 부모님과 연결하기`** 카드가 보입니다
- [ ] 그 카드를 누르면 ⚙️ 설정으로 갑니다
- [ ] `📱 내 QR 띄우기` 를 누르면 **QR 그림**이 뜹니다
- [ ] QR 아래에 카메라가 안 될 때 쓰는 **연결 코드**도 있습니다
- [ ] `부모님과 연결하지 않을래요` 를 누르면 **PIN 화면**이 뜹니다
      (데모 PIN 은 **1234** 입니다)
- [ ] PIN 을 넣으면 "연결하지 않기로 했어요" 가 뜨고, 홈의 연결 안내가 사라집니다

## ③ 아이 화면은 기존과 같은지

`🦊 아이 — 연결됨`

- [ ] 오늘의 학습 / 레벨 진도 / 국어 진도 / 오답 노트 / 단어장 / 학습 달력 /
      이번 달 개근 / 내 동기 부여 요청권 — **전부 그대로**입니다
- [ ] 연결이 끝났으므로 `부모님과 연결하기` 카드는 **안 보입니다**
- [ ] 맨 위 오른쪽에 **`⚙️ 서준 설정`** 하나만 있습니다
      (`👨‍👩‍👧 부모님` 버튼은 **없어졌습니다**)

> 부모님 모드로 들어가는 문은 `⚙️ 설정` **맨 아래**로 옮겼습니다. 아이 폰에서
> 눈에 안 띄는 자리이고, 어차피 뒤에 PIN 이 있어 아이가 눌러도 못 들어갑니다.
> 아주 없애면 이 폰에 부모 프로필을 만들어 둔 집이 자기 화면으로 못 돌아갑니다.

## ④⑤⑥ 부모가 자기 공부를 하는지

`👩‍💼 부모 — 아직 안 고름` → `무엇을 공부할지 정하기`
(고르는 자리는 이제 **`⚙️ 설정` → `내 공부 설정`** 입니다)

- [ ] **하루에 몇 개** 가 **갈래 카드 안마다** 있습니다 — `5개` / `10개`
      (예전에는 카드 밖에 하나만 있었고 그 값을 셋이 나눠 가졌습니다)
- [ ] 일상 문장을 `10개` 로 바꾸고 홈으로 가면 칩이 `일상 문장 10개` 가 됩니다
- [ ] **일상 생활 문장 학습하기** — 켜면 주제 8가지가 펼쳐집니다
      (업무와 협업 / IT와 개발 / 데이터와 인공지능 / 프로젝트 관리 /
      리더십과 경영진 소통 / 비즈니스 예절 / 협상과 문제 해결 / 가벼운 대화)
- [ ] **아이들과 같은 영어 단어 학습하기** — 켜면 **레벨 고르기**가 나옵니다
- [ ] **국어 어휘 학습하기** — 켜면 **레벨 고르기**가 나옵니다
- [ ] 여러 개를 켜면 `오늘 이 갈래에서 새로 N개를 만납니다` 숫자가 나뉩니다
- [ ] `돌아가기` → 홈으로 → `공부 시작하기`
- [ ] **문제 화면이 아이 것과 똑같습니다** — 빈칸 채우기, 4지선다, 해석 보기
- [ ] 문제를 풀면 낱말 카드가 뜨고 예문이 펼쳐집니다

## ⑦ 부모 화면 네 갈래

`👩‍💼 부모 — 아이 둘 등록됨`

- [ ] 맨 위 오른쪽에 **`⚙️ 설정`** 하나만 있습니다
- [ ] 홈은 세 덩이입니다 — **오늘의 공부 / 📈 내 학습 기록 / 아이들 학습 보고서**
- [ ] `오늘의 공부` 카드 안에 **갈래마다 개수가 붙은 칩 한 줄**만 있습니다

      ```
      [일상 문장 10개] [영어 단어 5개] [국어 5개]
      ```

- [ ] **숫자가 그 갈래의 개수입니다.** `일상 문장 10개` 는 일상 문장 10개예요.
      (예전 `하루에 10개` 는 셋이 나눠 갖는 합계였습니다 — 셋이면 4·3·3)
- [ ] **레벨도 주제도 안 적힙니다.** `중1-1` 도 `업무와 협업` 도 여기엔 없습니다
- [ ] 레벨과 주제는 `⚙️ 설정` → `내 공부 설정` 에서 고르고, 바로 아래
      `무엇을 얼마나 익혔나` 막대에 `국어 어휘 학습하기 · 중1-1` 처럼
      갈래 이름과 함께 나옵니다
- [ ] **학습 기록이 홈에 그대로 펼쳐져 있습니다** — 최근 7일, 무엇을 얼마나
      익혔나(갈래별), 이번 달 달력. 누르지 않아도 보입니다
- [ ] 맨 아래 **`부모 설정` 타일은 없어졌습니다**
- [ ] `아이들 학습 보고서` — **아이 목록**이 먼저 나옵니다 (서준 · 지호)
- [ ] 아이를 누르면 **그 아이 화면**이 열립니다
- [ ] 그 안에 **공부할 과목 / 하루 새 단어 수 / 복습 수 / 학습 강도 /
      해석 보기 / 학년·레벨 / 동기 부여 요청권 금액** 이 다 있습니다
- [ ] 서준과 지호의 설정이 **서로 다릅니다** (지호는 영어+국어, 하루 5개)
- [ ] `⚙️ 설정` 을 누르면 **버튼 두 개**가 나옵니다
      - `👧 아이들 폰 설정` — 알림 시각, 아이 기기 연결, **기본** 요청권 금액, 백업, PIN
      - `📚 내 공부 설정` — 무엇을 하루 몇 개씩 볼지

## ⑦-0 공부를 안 고른 부모는 보고서만

`👩‍💼 부모 — 아직 안 고름`

- [ ] 홈에 **`오늘의 공부` 카드가 아예 없습니다**
- [ ] **`📈 내 학습 기록` 도 없습니다**
- [ ] **`👧 아이들 학습 보고서` 만** 있습니다
- [ ] 맨 아래 한 줄 — `부모님도 공부하고 싶으시면 ⚙️ 설정 → 내 공부 설정 에서
      켜실 수 있어요`

> 부모님이 자기 공부를 안 하기로 한 것은 잘못이 아니라 하나의 선택입니다.
> 그래서 빈 카드로 매일 권하지 않고, 길만 한 줄로 남겨 두었습니다.

## ⑦-1 아이 기기 연결이 한 장으로

`👩‍💼 부모 — 아이 둘 등록됨` → `부모 설정`

- [ ] `🔗 아이 기기와 연결하기` 카드가 **한 장만** 있습니다 (예전엔 두 장)
- [ ] 그 안에 번호 붙은 두 갈래가 상자로 갈려 있습니다
      - `1. 아이폰에서 생성한 QR를 내폰에서 찍어 연결하기` → `📷 아이 QR 찍기`
      - `2. 내 폰에서 생성한 QR을 아이폰에서 찍어 연결하기` → `📱 내 QR 띄우기`
- [ ] 2번의 `📱 내 QR 띄우기` 를 누르면 QR 과 연결 코드가 뜹니다
- [ ] 제목 오른쪽에 **`2 / 4명`** 처럼 지금 몇 명인지 적혀 있습니다
- [ ] 그 아래 `지금 연결된 아이 — 서준 · 지호` 로 이름이 나옵니다

**아이가 4명이 되면** (아이를 넷까지 연결하시면)

- [ ] 칸이 **`4 / 4명`** 이 되고 노란 **`자리가 다 찼어요`** 상자가 뜹니다
- [ ] `📷 아이 QR 찍기` 와 `📱 내 QR 띄우기` 가 **눌리지 않습니다**
- [ ] 그래도 QR 을 찍으면 카메라 화면에 왜 안 되는지 한 줄 뜹니다

## ⑦-2 요청권 금액을 직접 적기

같은 화면 아래 `기본 동기 부여 요청권 금액 설정`

- [ ] 설명이 **두 줄**입니다 (예전 다섯 줄에서 줄였습니다)
- [ ] **중학교 영어 레벨 하나** — 고를 수 있는 금액이 `3만원`에서 끝납니다
- [ ] **고등학교 영어 레벨 하나** — `5만원`에서 끝납니다
- [ ] 맨 끝 **`기타`** 를 누르면 빈칸이 나오고 금액을 직접 적을 수 있습니다
- [ ] `45000` 을 적으면 칩이 `기타 · 45,000원` 으로 바뀝니다
- [ ] 권하는 선을 넘기면 (`80000`) 노란 글씨로 한 줄 알려 줍니다
- [ ] 맨 아래 **`합계 84만원`** 문구는 **없어졌습니다**

# 6장. 노트북으로는 확인 못 하는 것

정직하게 적습니다. **이 셋은 폰에서만 됩니다.**

| 무엇 | 왜 | 언제 확인 |
|---|---|---|
| **QR 찍기** | 브라우저 카메라가 폰과 다르게 동작합니다 | 폰 두 대로 한 번 |
| **푸시 알림** | 부모↔아이 사이 실제 전송은 폰에서만 됩니다 | 폰 두 대로 한 번 |
| **진동** | 브라우저에 없습니다 | 폰에서 |
| **폰의 실제 목소리** | 윈도우 목소리와 다릅니다 | 폰에서 (규칙은 같습니다) |

그래서 5장의 부모 화면은 **이미 연결된 뒤**를 심어 둔 것입니다. 연결된 다음의
화면은 전부 노트북에서 보실 수 있고, **연결하는 그 순간**만 폰이 필요합니다.

## 폰 두 대로 연결을 확인하는 법 (한 번만)

1. 아이 폰: ⚙️ 설정 → `📱 내 QR 띄우기`
2. 부모 폰: 아이들 학습 보고서 → `📷 아이 QR 찍기`
3. 찍는 즉시 부모 폰에 아이가 등록됩니다
4. 잠시 뒤 아이 폰에 `🔗 부모님 폰과 연결됐어요` 알림이 옵니다
   (아이는 아무것도 안 눌러도 됩니다)
5. 아이가 공부를 마치면 부모 폰으로 리포트가 옵니다

> 4번 알림이 안 오면 아이 폰의 **알림 권한**을 확인해 주세요. 안드로이드 13부터는
> 권한을 안 주면 아무것도 안 뜹니다.

# 7장. APK 만들어 폰에 넣기

노트북에서 다 확인하신 다음입니다.

## 먼저 — 정말 APK 를 다시 만들어야 하나요?

**대부분은 아닙니다.** 자바스크립트만 바뀐 것(화면 글귀, 예문, 단어 추가,
문제 배정)은 **1~2분** 만에 폰으로 밀어 넣을 수 있습니다.

```powershell
npx eas-cli@latest update --branch beta --message "무엇을 고쳤는지"
```

아이가 앱을 **껐다 켜면** 적용됩니다.

APK 를 다시 만들어야 하는 때는 이렇습니다.

- `expo-` 로 시작하는 **새 기능 꾸러미**가 늘었을 때
- `app.json` 의 앱 이름·권한·아이콘·판 번호가 바뀌었을 때
- **앱을 처음 까는 폰**일 때

## 빌드 전 점검

```powershell
npm run preflight
```

권한이 빠졌다든지 하는 것을 몇 초 만에 잡아 줍니다. 빌드는 10~20분이 걸리고
무료 계정은 월 횟수가 정해져 있어서, 걸기 전에 한 번 보는 편이 낫습니다.

## 빌드

```powershell
npx eas-cli@latest login
npx eas-cli@latest build --platform android --profile beta-android
```

10~20분 뒤 링크가 나옵니다. 그 링크를 **폰 브라우저로 열어** 내려받아 까시면
됩니다. 자세한 것은 [BETA.md](./BETA.md) 에 있습니다.

## 폰에 들어간 것이 맞는지 확인

앱 홈 화면 위쪽에 **`📱 0.13.1 (12)`** 같은 칩이 있습니다. 앞이 판 번호,
괄호 안이 빌드 번호입니다. 새로 깔았는데 둘 다 그대로면 옛 앱을 보고 계신
것입니다.

**그 칩을 누르면** 이번 판에 무엇이 들어 있는지 목록이 나옵니다. 거기 적힌
것이 회원님이 기대하신 것과 같으면 제대로 깔린 것입니다.

# 8장. 막혔을 때

| 이렇게 나오면 | 뜻 | 할 일 |
|---|---|---|
| `node : 인식할 수 없는 이름` | 노드가 없거나 창이 옛 창 | 1장. PowerShell 을 새로 여세요 |
| `Cannot find module` | 꾸러미가 없습니다 | `npm install` |
| `npm run preview` 에서 오류 | 굽다 실패 | 오류 줄을 저에게 그대로 보내 주세요 |
| 브라우저에 아무것도 안 뜸 | 주소가 틀렸습니다 | `http://localhost:8088/demo/` — 끝의 `/` 까지 |
| 고친 것이 안 보임 | `--fast` 로 옛 것을 씁니다 | `--fast` 빼고 다시 |
| `whats-in` 에 ❌ | 최신이 안 받아졌습니다 | 2장을 다시 |
| 포트가 쓰이는 중 | 8088 을 딴 것이 씁니다 | `$env:PORT=8090; npm run preview` |
| 화면이 하얗게만 | 브라우저 캐시 | `Ctrl` + `Shift` + `R` |

## 그래도 안 되면

PowerShell 창에 나온 **빨간 글씨를 통째로 복사해서** 저에게 주세요.
어디서 막혔는지 대개 그 줄에 적혀 있습니다.
