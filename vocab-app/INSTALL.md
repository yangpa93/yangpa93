# 설치 안내

두 딸의 기기가 달라서 **설치 경로도 둘**입니다. 하나씩 따로 읽으시면 됩니다.

| | **큰딸 — 아이폰** | **작은딸 — 안드로이드** |
|---|---|---|
| 방법 | **TestFlight** (애플 공식 베타 배포) | **APK 직접 설치** |
| 필요한 것 | **Apple Developer Program (연 129,000원)** | 없음 (무료) |
| 걸리는 시간 | 가입 승인 1~2일 + 빌드 30분 | 30분 |
| 알림 · 부모님 폰 전송 | ✅ | ✅ |
| 컴퓨터를 꺼도 | ✅ | ✅ |
| 앱 만료 | **90일마다 새 빌드 필요** | 만료 없음 |
| 자세히 | **[경로 1 →](#경로-1--큰딸-아이폰-testflight)** | **[경로 2 →](#경로-2--작은딸-안드로이드-apk)** |

두 경로 모두 **[0단계 — 컴퓨터 준비](#0단계--컴퓨터-준비-두-경로-공통)** 를 먼저 해야 합니다.
그 전에 화면부터 보고 싶으시면 **[먼저 훑어보기](#먼저-훑어보기-설치-없이)** 로 가세요.

> **돈을 안 쓰고 아이폰에 넣는 방법은 없나요?**
> 애플은 개인이 만든 앱을 다른 사람 아이폰에 정식으로 넣으려면 Developer Program을
> 요구합니다. 무료로 할 수 있는 것은 (1) Expo Go로 띄워 보기 — 컴퓨터를 켜 둬야 하고
> 부모님 폰 전송이 안 됩니다, (2) 맥 + Xcode로 직접 서명 — **7일마다 다시 설치**해야
> 합니다. 매일 쓸 앱으로는 둘 다 맞지 않아서 TestFlight를 권합니다.

안드로이드는 **폰과 태블릿이 같은 방법**입니다. 태블릿이라고 따로 할 일은 없습니다.
(태블릿에서는 화면이 가로로도 돌아가고, 글이 너무 넓게 퍼지지 않도록 가운데로 모입니다.)

## 먼저 훑어보기 (설치 없이)

### 컴퓨터 브라우저에서 — 가장 빠름

0단계를 마친 뒤 `vocab-app` 폴더에서:

```bash
npm run web
```

브라우저가 자동으로 열립니다. 안 열리면 터미널의 `http://localhost:8081` 을 직접 여세요.
**폰 화면처럼 보려면** 크롬에서 `F12` → 왼쪽 위 📱 아이콘 → `Galaxy S20` 같은 기기 선택.

| | 컴퓨터 브라우저 |
|---|---|
| 단어 학습, 문제 7종, 단어 카드 | ✅ |
| 오답 노트, 단어장, 학습 달력, 레벨 시험, 요구권 | ✅ |
| 부모님 모드, 리포트 화면 | ✅ |
| 발음 듣기 🔊 · 🎬 영상 보기 | ✅ (크롬 기준) |
| 진동 피드백 · 매일 알림 · 부모님 폰 전송 | ❌ |

학습 기록은 그 브라우저 안에만 저장됩니다. 폰에 설치하면 처음부터 새로 시작합니다.

### 폰에서 Expo Go로 — 아이폰·안드로이드 공통

App Store 또는 Play 스토어에서 **Expo Go** 를 설치하고, 컴퓨터에서:

```bash
npm start
```

터미널에 QR 코드가 뜹니다.

- **아이폰**: 기본 **카메라 앱**으로 QR을 찍고 뜨는 배너를 누릅니다.
- **안드로이드**: **Expo Go 앱을 열고** 그 안의 `Scan QR code` 로 찍습니다.
  (기본 카메라 앱으로 찍으면 열리지 않습니다.)

**컴퓨터와 폰이 같은 와이파이여야 합니다.** 회사·학교 와이파이라 안 되면
`Ctrl+C` 로 멈추고 `npx expo start --tunnel` 로 다시 띄우세요. 느리지만 어디서든 됩니다.

Expo Go의 한계: **컴퓨터를 켜 둬야 하고, 매일 알림과 부모님 폰 전송이 동작하지 않습니다.**
푸시 토큰이 발급되지 않기 때문입니다. 확인용으로만 쓰세요.

## 0단계 — 컴퓨터 준비 (두 경로 공통)

### 0-1. Node.js 설치 — 건너뛰지 마세요

터미널(윈도우는 **PowerShell**, 맥은 **터미널**)을 열고:

```bash
node --version
```

**`v18.0.0` 이상이 나와야** 다음으로 넘어갈 수 있습니다.

`'node' 용어가 ... 인식되지 않습니다` 또는 `command not found` 가 나오면 설치가 안 된 것입니다.
이 상태로 진행하면 나중에 `npm install` 에서 똑같은 오류가 납니다.

**윈도우** — https://nodejs.org 에서 **LTS** 버튼을 눌러 `.msi` 를 받고 계속 `Next`.
(윈도우 10/11이면 PowerShell에서 `winget install OpenJS.NodeJS.LTS` 한 줄로도 됩니다.)

> **설치가 끝나면 PowerShell 창을 완전히 닫고 새로 여세요.**
> 열려 있던 창은 예전 설정을 그대로 들고 있어서 `npm` 을 계속 못 찾습니다.
> 가장 많이 걸리는 부분입니다.

**맥** — https://nodejs.org 에서 LTS `.pkg` 를 받아 설치하거나, Homebrew가 있으면 `brew install node`.

새 터미널에서 둘 다 버전이 나와야 합니다.

```bash
node --version
npm --version
```

### 0-2. 코드 받기

**브랜치를 지정해서 받으세요.** `vocab-app` 폴더는 기본 브랜치(`main`)에는 없고
아래 기능 브랜치에만 있습니다.

```bash
git clone -b claude/english-vocab-learning-app-pfy9yg https://github.com/yangpa93/yangpa93.git
cd yangpa93/vocab-app
ls
```

`package.json`, `app.json`, `src` 등이 보이면 성공입니다.

> **이미 브랜치 없이 clone 하셨다면** 다시 받을 필요 없이 브랜치만 바꾸면 됩니다.
> ```bash
> cd yangpa93
> git checkout claude/english-vocab-learning-app-pfy9yg
> cd vocab-app
> ```
> `cd yangpa93/vocab-app` 을 **먼저** 하면 "경로를 찾을 수 없습니다" 오류가 납니다.
> 브랜치를 바꾸기 전에는 그 폴더가 아직 없기 때문입니다.

> `git` 이 없다는 오류가 나면 https://git-scm.com 에서 설치하시거나,
> GitHub 페이지에서 브랜치를 고른 뒤 `Code → Download ZIP` 으로 받아 압축을 푸셔도 됩니다.

### 0-3. 패키지 설치

```bash
npm install
```

처음 한 번 2~5분 걸립니다. 중간에 `deprecated`, `warn` 같은 노란 글씨가 여러 줄 나오는데
**정상입니다.** 빨간 `ERR!` 만 아니면 넘어가세요.

> **PowerShell에서 `npm.ps1 파일을 로드할 수 없습니다` 오류가 나면** 스크립트 실행이 막혀 있는 것입니다.
> 아래 한 줄을 실행하고 `Y` 를 누른 뒤 다시 시도하세요.
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

### 0-4. Expo 계정 · 빌드 도구 (두 경로 공통)

두 경로 모두 Expo 클라우드가 대신 빌드해 줍니다. 컴퓨터에 Xcode나 Android Studio를
설치할 필요가 없습니다.

1. **Expo 계정 만들기 (무료)** — https://expo.dev/signup, 이메일만 있으면 됩니다.

2. **빌드 도구 준비**

   `eas`는 **프로젝트가 아니라 컴퓨터에 따로 있는 도구**입니다. `npm install` 을
   했다고 생기지 않습니다. 설치 없이 바로 쓰려면 `npx` 로 부르면 됩니다.

   ```bash
   npx eas-cli@latest --version
   ```

   처음 한 번 `Ok to proceed?` 를 물으면 Enter를 누르세요. 아래 명령들도 전부
   `npx eas-cli@latest ...` 형태로 쓰시면 됩니다.

   매번 `npx` 를 붙이기 싫으면 컴퓨터에 깔아 두셔도 됩니다.

   ```bash
   npm install -g eas-cli
   ```

   > **깔고 나면 터미널 창을 완전히 닫고 새로 여세요.** 열려 있던 창은 예전
   > PATH를 들고 있어서 방금 깐 `eas` 를 계속 못 찾습니다. 윈도우에서
   > `'eas' 용어가 ... 인식되지 않습니다` 가 나오는 이유가 대부분 이것입니다.
   > 새 창에서 `eas --version` 이 뜨면 그때부터 `eas build ...` 로 짧게 쓰시면 됩니다.
   >
   > 맥/리눅스에서 권한 오류가 나면 앞에 `sudo` 를 붙이세요.

3. **로그인**

   ```bash
   npx eas-cli@latest login
   ```

   비밀번호는 화면에 안 보이는 게 정상입니다.

4. **프로젝트 연결** — `vocab-app` 폴더 안에서

   ```bash
   npx eas-cli@latest init
   ```

   - `Would you like to create a project?` → **y**
   - 프로젝트 이름을 물으면 그냥 Enter (기본값 `vocab-app`)

   `app.json` 에 프로젝트 ID가 자동으로 채워집니다.

> **`eas init` 은 반드시 해야 합니다.** 이걸 빼고 빌드하면 앱은 설치되지만
> **부모님 폰 전송이 동작하지 않습니다** (`프로젝트 ID가 없습니다` 오류).

여기까지가 공통입니다. 이제 각자의 경로로 갑니다.

# 경로 1 — 큰딸 아이폰 (TestFlight)

TestFlight는 애플이 제공하는 공식 베타 배포 서비스입니다. 큰딸은 App Store에서
**TestFlight** 앱을 받고, 초대 메일을 눌러 설치합니다. 스토어에 앱을 공개하지 않아도 됩니다.

전체 흐름:

```
Apple Developer Program 가입 (1~2일)
  → App Store Connect에 앱 등록
  → eas build --platform ios
  → eas submit → TestFlight에 올라감
  → 큰딸을 테스터로 초대
  → 큰딸이 TestFlight 앱에서 설치
```

## 1-1. Apple Developer Program 가입

**연 129,000원(미국 $99)이고, 개인 명의로 가입하면 됩니다.**

1. https://developer.apple.com/programs/enroll/ 접속
2. 애플 계정으로 로그인 — **2단계 인증이 켜져 있어야** 합니다
   (안 되어 있으면 아이폰 `설정 → [내 이름] → 로그인 및 보안` 에서 먼저 켜세요)
3. `Individual / Sole Proprietor` 선택 (회사가 아니면 이쪽)
4. 이름·주소를 **영문**으로 입력합니다. 신분증 확인을 요구할 수 있습니다
5. 결제 후 **승인까지 보통 24~48시간** 걸립니다

> **가입 승인을 기다리는 동안** 0단계와 아래 1-2까지 해 두시면 승인 즉시 빌드로 넘어갈 수 있습니다.
> 그동안 큰딸에게는 Expo Go로 먼저 보여 주셔도 됩니다.

승인 메일이 오면 https://appstoreconnect.apple.com 에 들어가지는지 확인하세요.

## 1-2. 앱 이름과 식별자 확인

이 앱은 이미 아래 값으로 설정되어 있습니다. 바꿀 필요 없습니다.

| 항목 | 값 | 어디에 |
|---|---|---|
| 앱 이름 | 우리 영단어 | `app.json` → `expo.name` |
| Bundle ID | `com.yangpa93.urivocab` | `app.json` → `expo.ios.bundleIdentifier` |
| 버전 | 0.9.0 (베타) | `app.json` → `expo.version` |

> **Bundle ID는 전 세계에서 유일해야 합니다.** `com.yangpa93.urivocab` 은 이미
> 개인 식별자가 들어 있어 겹칠 가능성이 거의 없습니다. 혹시 "이미 사용 중"이라고 나오면
> `app.json` 의 `ios.bundleIdentifier` 와 `android.package` 를 `com.yangpa93.urivocab2`
> 처럼 바꾸고 다시 빌드하세요.

## 1-3. 빌드 만들기

`vocab-app` 폴더에서:

```bash
npx eas-cli@latest build --platform ios --profile production
```

처음 한 번만 묻는 것들:

- `Do you want to log in to your Apple account?` → **y**
  → 애플 계정 아이디·비밀번호 → 아이폰으로 오는 **6자리 인증 코드** 입력
- `Generate a new Apple Distribution Certificate?` → **y**
- `Generate a new Apple Provisioning Profile?` → **y**
- `Would you like to register a new app on App Store Connect?` → **y**
  (App Store Connect에 앱 항목이 자동으로 만들어집니다)
- 푸시 알림 키(APNs)를 만들지 물으면 → **y**
  **이걸 만들어야 부모님 폰 전송이 동작합니다.**

인증서와 키는 Expo가 만들어 보관합니다. **직접 관리할 필요 없습니다.**

```
✔ Build queued...
🚀 https://expo.dev/accounts/.../builds/xxxx
```

**20~40분** 걸립니다. 터미널을 닫아도 클라우드에서 계속 진행되고, 위 링크에서
진행 상황이 실시간으로 보입니다.

## 1-4. TestFlight에 올리기

빌드가 끝나면:

```bash
npx eas-cli@latest submit --platform ios --latest
```

- 애플 계정을 다시 물으면 같은 계정으로 로그인
- `Apple Team` 을 고르라고 하면 방금 가입한 팀 선택

업로드는 몇 분이면 끝나지만, **애플이 빌드를 처리(Processing)하는 데 10~30분** 더 걸립니다.
App Store Connect → `TestFlight` 탭에서 상태가 `처리 중` → `테스트 준비 완료` 로 바뀌면 됩니다.

> **`수출 규정 준수 정보` 를 묻는 표시가 뜨면** — 이 앱은 HTTPS만 쓰므로
> `아니요, 앱에서 암호화를 사용하지 않습니다` 를 고르면 됩니다.
> (한 번 답하면 다음 빌드부터는 안 묻습니다.)

## 1-5. 큰딸을 테스터로 초대

**내부 테스터(Internal Testing)** 로 넣으면 **베타 심사 없이 바로** 설치할 수 있습니다.
최대 100명까지 가능하고, 우리는 두세 명이면 충분합니다.

1. App Store Connect → **사용자 및 액세스** → `+` → 큰딸의 **애플 계정 이메일** 추가
   - 역할은 `App Manager` 또는 `Developer`
   - 큰딸에게 초대 메일이 갑니다 → 눌러서 수락
2. App Store Connect → **TestFlight** → 왼쪽 `내부 테스트` → `+` 로 그룹 생성 (예: `가족`)
3. 그 그룹에 큰딸을 추가하고, **빌드를 그룹에 배포**합니다

> **외부 테스터(External)** 로 하면 애플의 **베타 앱 심사**를 거쳐야 하고 하루 이틀 걸립니다.
> 가족끼리 쓸 거라면 **내부 테스터**로 하세요.

## 1-6. 큰딸 아이폰에서 설치

1. App Store에서 **TestFlight** 앱 설치
2. 초대 메일의 `View in TestFlight` 를 누르거나, TestFlight 앱을 열면 **우리 영단어** 가 보입니다
3. `설치` → 홈 화면에 아이콘이 생깁니다
4. 첫 실행에서 **알림 권한을 묻습니다 → 반드시 허용**
   (거부하면 매일 리포트와 부모님 폰 전송이 동작하지 않습니다.
   나중에 `설정 → 우리 영단어 → 알림` 에서 켤 수 있습니다.)

## 1-7. 90일마다 다시 올리기 — 꼭 기억하세요

**TestFlight 빌드는 업로드 후 90일이 지나면 만료되어 앱이 열리지 않습니다.**
학습 기록은 기기에 남아 있으므로 새 빌드를 설치하면 그대로 이어집니다.

만료 전에 이 두 줄만 다시 실행하면 됩니다.

```bash
npx eas-cli@latest build --platform ios --profile production
npx eas-cli@latest submit --platform ios --latest
```

큰딸의 TestFlight 앱에 `업데이트` 버튼이 뜹니다. 달력에 90일 알림을 걸어 두세요.

> 나중에 App Store에 정식 출시하면 만료가 없어집니다. 다만 심사와 개인정보 처리방침이
> 필요해서, 가족끼리 쓰는 동안은 TestFlight가 편합니다.

# 경로 2 — 작은딸 안드로이드 (APK)

Expo 서버가 대신 빌드해 주고, 완성된 `.apk` 파일을 받아 폰에 넣습니다.
**개발자 등록비가 없고, 만료도 없습니다.**

## 2-1. 빌드 실행

`vocab-app` 폴더에서:

```bash
npx eas-cli@latest build --platform android --profile preview
```

처음 한 번만 묻는 것:

- `Generate a new Android Keystore?` → **y**
  (앱 서명 열쇠입니다. Expo가 만들어 보관합니다. **직접 관리할 필요 없습니다.**)

```
✔ Build queued...
🚀 https://expo.dev/accounts/.../builds/xxxx
```

**10~20분** 걸립니다. 터미널을 닫아도 클라우드에서 계속 진행됩니다.

> **이 키스토어를 잃어버리면 기존 앱 위에 업데이트 설치가 안 됩니다.** Expo가 보관해 주니
> 같은 Expo 계정으로만 계속 빌드하시면 됩니다.
> 무료 계정은 월 빌드 횟수 제한이 있는데 가족용으로는 충분합니다.

## 2-2. 폰에 설치

빌드가 끝나면 터미널에 **QR 코드**가 뜹니다.

1. 폰 **기본 카메라 앱**으로 QR을 찍습니다 → 다운로드 페이지가 열립니다
   (또는 위 `expo.dev` 링크를 카톡으로 자신에게 보내 폰에서 열고 `Install`)
2. `Install` 을 눌러 `.apk` 를 내려받습니다
3. 다운로드 알림을 누르면 **"이 출처의 앱은 설치할 수 없습니다"** 경고가 뜹니다
   → `설정` 버튼 → **"이 출처 허용"** 켜기 → 뒤로 → `설치`
   (스토어를 안 거친 앱이라 나오는 정상 경고입니다)
4. 홈 화면에 **우리 영단어** 아이콘이 생깁니다
5. 첫 실행에서 **알림 권한을 묻습니다 → 반드시 허용**
   (안드로이드 13 이상에서 거부하면 리포트 알림이 오지 않습니다.
   나중에 `설정 → 앱 → 우리 영단어 → 알림` 에서 켤 수 있습니다.)

> **설치가 끝나면 "이 출처 허용"을 다시 꺼 두세요.** 켜 둔 채로 두면
> 나중에 다른 경로로 악성 앱이 설치될 여지가 생깁니다.

## 2-3. 요구하는 권한

설치할 때 확인해 보시면 이것뿐입니다.

| 권한 | 왜 필요한가 |
|---|---|
| 알림 | 매일 학습 리포트 |
| 진동 | 정답/오답 피드백 |
| 인터넷 | 🎬 YouGlish 영상 열기, 부모님 폰으로 리포트 전송 |

저장소 접근, 다른 앱 위에 표시 같은 불필요한 권한은 **명시적으로 차단**해 두었습니다
(`app.json` 의 `blockedPermissions`). 카메라·연락처·위치·마이크는 처음부터 요구하지 않습니다.

## 2-4. 나중에 업데이트할 때

`eas build --platform android --profile preview` 를 다시 실행하고, 나온 APK를
**기존 앱 위에 그대로 설치**합니다. 지울 필요 없고 **학습 기록도 그대로 남습니다.**

> 같은 Expo 계정(=같은 키스토어)으로 빌드해야 덮어쓰기가 됩니다.
> 다른 키로 만든 APK는 `앱이 설치되지 않았습니다` 오류가 납니다.

## (선택) USB 직접 설치

Android Studio를 **이미** 쓰고 계시면 클라우드를 거치지 않아도 됩니다.
다만 SDK 포함 **10GB 이상**이 필요해서, 이것만을 위해 설치할 이유는 없습니다.

1. https://developer.android.com/studio 에서 Android Studio 설치
2. 폰에서 **개발자 옵션** 켜기: `설정 → 휴대전화 정보 → 빌드 번호` 를 **7번 연속 탭**
3. `설정 → 개발자 옵션 → USB 디버깅` 켜기
4. USB로 연결 → 폰에 뜨는 `USB 디버깅을 허용하시겠습니까?` → **허용**
5. `npx expo run:android --variant release`

첫 빌드는 10~30분 걸립니다. 끝나면 폰에 자동 설치됩니다.

# 부모님 폰으로 결과 받기 (두 경로 공통)

아이가 학습을 마치면 **부모님 폰으로 알림이 바로 갑니다.** 서버 없이 Expo 푸시 서비스를
중계로 씁니다.

**Expo Go에서는 동작하지 않습니다.** TestFlight로 받은 앱이나 APK로 설치한 앱이어야
푸시 토큰이 나옵니다.

## 준비

- 부모님 폰에도 **같은 앱**을 설치합니다
  - 부모님이 아이폰이면 → 경로 1의 TestFlight 그룹에 부모님 계정도 추가
  - 부모님이 안드로이드면 → 경로 2의 APK를 그대로 설치
- **아이 기기마다 한 번씩** 연결합니다. 두 딸이 기기를 따로 쓰므로 **두 번** 하셔야 합니다.

## 1. 부모님 폰에서

1. 앱 실행 → 홈 화면 오른쪽 위 `👨‍👩‍👧 부모님` → PIN 설정
2. `설정` → **부모님 폰 연결하기**
3. 맨 아래 **이 폰을 부모님 전용으로 쓰기** 를 누릅니다
   - 알림 권한을 물으면 **허용**
   - 이후 이 폰은 학습 화면 대신 **리포트 화면**으로 열립니다
4. 폰 이름을 적습니다 (예: `엄마 폰`)
5. **연결 링크 보내기** → 카카오톡으로 **아이에게** 보냅니다

> `프로젝트 ID가 없습니다` 라고 나오면 컴퓨터에서 `eas init` 을 하지 않고 빌드한 것입니다.
> 0-4를 실행하고 앱을 다시 만들어 설치해 주세요.

## 2. 아이 기기에서

카카오톡으로 받은 **링크를 누르면** 앱이 열리고 "부모님 폰과 연결할까요?" 가 뜹니다.
`네, 연결할게요`.

링크가 안 열리면:

1. 카톡 메시지에서 `ExponentPushToken[...]` 부분을 길게 눌러 복사
2. 아이 기기 → `👨‍👩‍👧 부모님` → `설정` → **부모님 폰 연결하기**
3. 붙여넣고 `연결하기`

카메라 권한이 필요 없도록 QR 스캔 대신 링크·붙여넣기 방식을 썼습니다.

## 3. 바로 확인하기

아이 기기의 `부모님 폰 연결` 화면에서 **지금 한 번 보내보기** 를 누릅니다.
몇 초 안에 부모님 폰에 알림이 뜨면 성공입니다.

```
📚 서준 학습 리포트
서준 · 오늘 목표 완료! 20개 · 정답률 87% · 3일 연속
```

## 아이가 공부를 안 한 날

아이 기기가 꺼져 있으면 아무것도 오지 않습니다. 그래서 **부모님 폰이 정해진 시각에 스스로**
`📭 오늘 학습 리포트가 오지 않았어요` 알림을 띄웁니다.
시각은 부모님 폰 → `알림 시각 설정` 에서 바꿉니다.

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| `Expo Go에서는 푸시 토큰을 받을 수 없습니다` | Expo Go로 실행 중입니다. TestFlight 앱이나 APK에서 하세요 |
| `프로젝트 ID가 없습니다` | 컴퓨터에서 `eas init` 후 앱을 다시 빌드하세요 |
| `네트워크에 연결할 수 없습니다` | 아이 기기가 인터넷에 연결돼 있는지 확인 |
| 알림이 안 뜸 (아이폰) | `설정 → 우리 영단어 → 알림` 허용, **집중 모드**가 꺼져 있는지 확인 |
| 알림이 안 뜸 (안드로이드) | 알림 권한, `설정 → 배터리 → 앱 절전 관리` 에서 이 앱 제외 |
| 아무 일도 안 일어남 | 부모님 모드 → `학습 후 자동 전송` 이 켜져 있는지 확인 |

# 설치 후 — 첫 설정 (두 경로 공통)

1. 앱을 열면 **프로필 만들기** 화면이 나옵니다.
   이름(별명도 괜찮습니다), 캐릭터, 시작 학년과 레벨을 고르고 `시작하기`.
   > 지금 학년보다 한 단계 낮게 시작하셔도 됩니다. 레벨 시험에 통과하면 자동으로 올라갑니다.

2. 홈 화면 오른쪽 위 **`👨‍👩‍👧 부모님`** → PIN 4자리를 정하고, 한 번 더 입력해 확인합니다.

3. 알림 권한을 묻습니다 → **허용**

4. 부모님 모드 → `설정` 에서 **하루 새 단어 수**(기본 10개), **하루 복습 수**(기본 10개),
   학습 강도(2~4회), 알림 시각(오후 6~10시)을 조정합니다.

5. 아이가 여러 명이면 홈 화면에서 아이 이름을 눌러 → `+ 아이 추가하기`.
   **두 딸이 기기를 따로 쓰면 각 기기에 한 명씩** 만드는 편이 낫습니다.

# 문제가 생기면

## 공통

**`'npm' 용어가 ... 인식되지 않습니다`**
Node.js가 설치되지 않았거나, 설치 후 터미널을 다시 열지 않은 것입니다. **0-1** 을 다시 보세요.

**`cd yangpa93/vocab-app` 에서 "경로를 찾을 수 없습니다"**
아직 기본 브랜치(`main`)에 있어서 그 폴더가 없는 상태입니다. `cd yangpa93` 까지만 들어간 뒤
`git checkout claude/english-vocab-learning-app-pfy9yg` 를 먼저 실행하고 나서 `cd vocab-app`.

**`fatal: not a git repository`**
저장소 폴더 **밖**에서 git 명령을 실행한 것입니다. `cd yangpa93` 으로 들어간 뒤 다시 실행하세요.
지금 어디인지는 `pwd`(윈도우도 동작)로 확인할 수 있습니다.

**`git pull` 이 `Your local changes to the following files would be overwritten` 로 막힙니다**
Expo가 실행될 때마다 `tsconfig.json` 을 자기 형식으로 다시 쓰기 때문입니다. 자동 생성물이라 버려도 안전합니다.
`vocab-app` 폴더 안에서:

```powershell
git checkout -- tsconfig.json
git pull origin claude/english-vocab-learning-app-pfy9yg
```

`.\update.ps1` 을 쓰시면 이 과정을 대신해 줍니다.

> git에 파일 경로를 줄 때는 **지금 있는 폴더 기준**입니다. 오류 메시지에는 저장소 최상위 기준
> 경로(`vocab-app/tsconfig.json`)가 찍히는데, `vocab-app` 안에서는 `tsconfig.json` 이라고만 써야 합니다.

**`fatal: unable to access ... Could not resolve host: github.com`**
git 문제가 아니라 네트워크 문제입니다.
① 잠시 뒤 다시 시도 (일시적 DNS 문제가 흔합니다)
② `ping github.com` — 응답이 없으면 인터넷 자체가 막힌 것입니다
③ **회사·학교 네트워크는 github.com을 차단하는 경우가 많습니다.** 집이나 핫스팟에서 시도
④ VPN을 쓰고 계시면 잠시 꺼 보세요
⑤ 예전 프록시 설정 확인: `git config --global --get http.proxy`
　 (지금 안 쓰는 주소가 나오면 `git config --global --unset http.proxy`)

**`npm install` 에서 빨간 `ERR!` 가 납니다**
`node --version` 으로 18 이상인지 확인하세요. 그래도 안 되면 `vocab-app` 폴더의
`node_modules` 폴더와 `package-lock.json` 파일을 지우고 다시 `npm install`.

**`eas: command not found`** 또는 **`'eas' 용어가 ... 인식되지 않습니다`**

`eas` 는 프로젝트가 아니라 컴퓨터에 따로 있는 도구라, `npm install` 을 했다고 생기지 않습니다.
가장 빠른 해결은 **설치 없이 `npx` 로 부르는 것**입니다.

```bash
npx eas-cli@latest login
npx eas-cli@latest init
npx eas-cli@latest build --platform android --profile beta-android
```

깔아서 쓰고 싶으시면 `npm install -g eas-cli` 뒤에 **터미널을 완전히 닫고 새로 여세요.**
