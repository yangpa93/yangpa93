## 어휘를 손보는 길 (도구 정리)

```bash
npm run export        표를 뽑는다 (영어·국어·일상 문장 CSV 세 장)
                      → 엑셀에서 고친다
```

**국어**

```bash
npm run apply-korean              무엇이 바뀌는지 보여만 준다
npm run apply-korean -- --write   korean/corrections.json 에 적는다
node scripts/korean/build-levels.mjs
```

**영어 (지우는 것만)**

```bash
python scripts/xlsx-sheet-to-csv.py review/2027_영어_단어.xlsx vocab review/영어-단어.csv
npm run apply-english             무엇이 빠지는지 보여만 준다
npm run apply-english -- --write  실제로 지운다
node scripts/build-plan.mjs > src/data/plan.ts
```

### 알아 둘 것

- `npm run export` 는 **손보신 표를 덮어쓰기 전에 옆에 치워 둡니다**
  (`국어-어휘.손본것-20260805-1030.csv`). 반나절 들인 파일이 사라지지 않습니다.
- 엑셀은 `scripts/xlsx-sheet-to-csv.py` **한 곳에서만** 읽습니다.
  나머지 도구는 전부 CSV 로 다룹니다.
- 낱말 하나가 **다섯 곳**에 걸쳐 있습니다 — levels/*.ts · plan.ts ·
  placement.json · antonyms.ts · spelling.ts. `apply-english` 가 다 치웁니다.
- 교육부 원본 목록(`data/*.txt`)은 **손대지 않습니다.** 안 가르칠 것은
  `data/not-taught.json` 에 이유와 함께 적습니다.
- 국어 원본 엑셀도 손대지 않습니다. 교정은 `korean/corrections.json` 에.
