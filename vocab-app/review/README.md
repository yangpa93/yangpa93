# 단어 확인용 파일

아이가 무엇을 외우고 있는지 직접 훑어볼 수 있게 뽑아 둔 것입니다.
데이터 자체는 `src/data/levels/*.ts` 에 코드로 들어 있어서 그대로는 읽기 어렵습니다.

| 파일 | 쓰는 곳 |
|---|---|
| `vocab.csv` | 엑셀·구글시트로 열어 정렬하고 걸러 봅니다. 예문 한 줄이 한 행입니다. |
| `vocab.html` | 폰이나 브라우저에서 그냥 엽니다. 검색과 레벨 고르기가 됩니다. |

두 파일 모두 **뽑아 둔 것**이라 단어를 고치면 다시 만들어야 합니다.

```
npm run export          # review/ 아래에 다시 만든다
npm run export 다른폴더   # 다른 곳에 만들고 싶을 때
```

## 이상한 것을 찾으면

무엇이 이상한지(단어·뜻·예문 중 어느 칸인지) 적어 주시면 고칩니다.
표제어의 **철자**를 바꾸면 그 단어의 학습 기록이 끊기므로, 철자를 고칠 때는
따로 말씀드립니다.

## 기계로 거르는 것

사람이 예문 1만 개를 다시 읽을 수는 없어서, 걸러낼 수 있는 것은 기계에 맡깁니다.

```
npm run audit words_alpha.txt   # 철자 · 문장 형식 · 한국어 해석 · 뜻 · 동의어
npm run verify wordnet          # 품사 · 유의어 · 반대말을 WordNet 사전과 대조
```

두 자료는 저장소에 넣지 않습니다(용량과 라이선스). 받는 방법은 각 스크립트
맨 위 주석에 적혀 있습니다.
